## 🎯 核心公式

### Seedance 2.0 提示词公式（由浅入深）

**基础版（≤12秒短视频）**：
```
[主体] + [动作] + [环境/光影] + [运镜] + [风格]
```

**进阶版（天赐公式）**：
```
主体 + 动作 + 场景 + 镜头 + 色调 + 风格
```

**专业版（带参考素材）**：
```
[角色]@图片N + [动作/剧情] + [场景]@图片N + [运镜参考]@视频N
```

### 10秒电商短视频黄金结构
```
[0-3s] 痛点切入 → [3-7s] 功能展示 → [7-10s] 效果收尾
  ❌旧: "不太好用"     ❌旧: "用它就好了"    ❌旧: "推荐购买"
  ✅新: 具体场景描写   ✅新: 分镜展示过程   ✅新: 自然夸赞
```

## 🔄 多样化4技巧

| 技巧 | 方法 | 举例 |
|------|------|------|
| ① **换场景** | 同一产品不同场景 | 浴室→卧室→窗边→厨房 |
| ② **换镜头** | 不同运镜方式 | 推近→环绕→俯拍→跟拍 |
| ③ **换色调** | 不同色彩氛围 | 明亮→暖色→冷调→自然 |
| ④ **换痛点角度** | 不同切入角度 | 使用前困扰→对比→效果展示 |

## ⛔ 避坑清单
- ❌ 禁止高速动作（画面模糊）
- ❌ 禁止复杂多人互动（角色混淆）  
- ❌ 禁止模糊/抽象词（"好看""很美""高级"）
- ❌ 禁止写实真人面部（平台拦截）
- ❌ 禁止色情/暴力/版权人物
- ✅ 一个视频只做一件事
