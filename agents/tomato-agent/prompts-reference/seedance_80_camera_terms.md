# Seedance 80个运镜术语库（天赐提供）

## 一、基础运动镜头（让画面动起来）

### 1、推拉运镜（控制角色情绪）
- **缓慢推入镜头**：慢慢靠近，聚焦或制造紧张 → 镜头缓慢向主体推入
- **快速拉出镜头**：瞬间后退，展示反差 → 镜头从特写快速向后拉出至全景
- **微距缓推镜头**：极慢靠近微小细节 → 微距镜头，极慢速向局部细节推入
- **后退揭示镜头**：边退边看清大环境 → 镜头向后退，逐渐展现广阔场景
- **推进亲密镜头**：向角色脸部靠近 → 镜头平滑推向角色脸部
- **后退疏远镜头**：远离角色表现冷漠 → 镜头慢慢从角色身旁向后拉远

### 2、移动轨迹（引导视线）
- **横摇跟随镜头**：水平跟着物体走 → 镜头水平横向平移，跟随运动的主体
- **垂直升降镜头**：上下移动看落差 → 镜头垂直上升/下降
- **对角线移动镜头**：斜着走，画面不稳定 → 镜头沿对角线斜向移动
- **弧形绕摄镜头**：绕主体走半圈 → 镜头围绕主体做半圆形弧线运动
- **抛物线运动镜头**：抛物线动感 → 镜头呈抛物线轨迹越过主体
- **Z轴纵深镜头**：前后直走强调深度 → 镜头沿前后方向做深焦纵深移动

### 3、特殊移动（增加真实感）
- **手持灵动镜头**：模拟手拿相机 → 手持镜头风格，带有轻微真实的呼吸晃动
- **轨道平移镜头**：平稳左右滑行 → 轨道镜头，绝对平稳的纯水平横移
- **旋转镜头**：绕人转360度 → 镜头围绕中心主体做360度环绕旋转
- **俯冲下降镜头**：高处猛冲下来 → 镜头从高空俯角快速向下俯冲
- **爬升仰视镜头**：从下往上猛升 → 镜头从低角度仰视，快速向上爬升
- **穿梭运动镜头**：在杂物中穿行 → 镜头在多个前景遮挡物之间灵活穿梭

### 4、速度控制（改变节奏）
- **渐进加速镜头**：越走越快 → 镜头移动速度逐渐加快
- **减速凝滞镜头**：越走越慢停下 → 镜头平滑减速，直至完全静止
- **急停定帧镜头**：猛然刹车定格 → 镜头快速移动后突然急停，画面定格
- **旋转俯冲镜头**：边转边冲向 → 镜头同时进行螺旋旋转与向下俯冲

### 5、转场（切换场景）
- **甩镜转场**：猛甩模糊画面切场景 → 快速甩镜头，带有强烈的动态模糊转场
- **遮挡转场**：被物体挡住瞬间换景 → 镜头移动到前景物体后方被遮挡
- **匹配剪辑**：相似形状直接连 → 匹配剪辑，利用相似的几何形状连接
- **主观视角镜头**：镜头当角色眼睛 → 第一人称主观视角，模拟角色的眼睛运动

### 6、构图
- **倾斜构图（荷兰角）**：画面歪着表现不安 → 荷兰角构图，镜头倾斜
- **分屏对比镜头**：画面切开同时放两件事 → 分屏效果，同时展示两个视角
- **画中画镜头**：大画面里套小画面 → 画中画效果
- **镜头呼吸效果**：忽近忽远像呼吸 → 轻微的镜头呼吸效应，焦距微弱周期性变化

## 二、情绪表达镜头（展示内心）

### 1、细微情绪
- **颤抖特写**：放大发抖的手/嘴唇 → 极度特写颤抖的[部位]，高频微小晃动
- **瞳孔放大镜头**：极近拍眼睛睁大 → 眼部极度微距特写，瞳孔放大
- **眼泪滑落镜头**：跟着眼泪掉 → 微距跟踪镜头，跟随一滴眼泪向下坠落
- **凝视长镜头**：完全不动盯很久 → 长镜头，完全静止，锁定角色的凝视
- **喘息跟拍**：跟着胸口起伏 → 镜头上下起伏，与角色沉重的呼吸同步

### 2、心理状态
- **旋转晕眩镜头**：一直转，表现头晕 → 眩晕效果，镜头连续旋转
- **模糊转清镜头**：从不清变清楚 → 焦点从模糊逐渐过渡到清晰锐利
- **清转变糊镜头**：从清楚变模糊 → 画面慢慢失焦，过渡到完全模糊
- **倾斜失衡镜头**：慢慢变歪，表现崩溃 → 动态倾斜镜头，角度逐渐变大
- **躲避晃动镜头**：剧烈乱晃 → 无规则的剧烈镜头晃动，模拟躲避动作

### 3、关系展示
- **拥抱环绕镜头**：绕着抱在一起的人转 → 镜头平滑地环绕正在拥抱的两人
- **争吵跳切镜头**：脸上生硬地切来切去 → 在两个角色之间进行快速跳切
- **孤独广角镜头**：大环境里拍小的人 → 超广角镜头，角色在空旷空间中渺小
- **压迫俯拍镜头**：正上方往下拍 → 高角度俯拍，直视下方角色
- **无力仰角镜头**：低处往上拍 → 低角度仰拍角色，表现无力感

### 4、回忆与时间
- **回忆叠化镜头**：两个画面半透明叠 → 交叉叠化转场
- **碎片剪辑镜头**：一闪一闪切很碎 → 快速蒙太奇剪辑，闪烁的记忆碎片
- **长镜压抑镜头**：一镜到底不切 → 一镜到底的连续长镜头

### 5、群体反应
- **快速变焦群镜头**：在几人脸上瞬间拉近切远 → 在多个角色面部之间极速推拉变焦

## 三、动作镜头（拍出打击感）

### 1、隐秘行动
- **潜行微动镜头**：走得极慢极轻 → 极其缓慢、隐蔽的镜头跟随移动
- **狙击视角镜头**：瞄准镜框+呼吸抖动 → 狙击枪瞄准镜视角，十字准星和呼吸起伏

### 2、追逐
- **汽车追逐镜头**：颠簸+速度模糊 → 强烈的上下颠簸与动态模糊
- **屋顶跑酷镜头**：忽高忽低跟着跳 → 镜头高度随角色跳跃变化
- **冲刺追逐镜头**：侧面跟着跑 → 侧面高速平移跟拍奔跑的角色
- **攀爬仰拍镜头**：从下往上跟着爬 → 低角度仰视跟拍

### 3、打斗
- **打斗跟随镜头**：贴着拳脚猛烈晃动 → 近距离格斗跟拍，随出拳剧烈移动
- **飞踢俯冲镜头**：镜头绑在脚上踢过去 → 随飞踢动作快速向目标俯冲
- **躲避翻滚镜头**：贴着地跟着滚 → 贴地镜头，跟随角色翻滚
- **剑光划过镜头**：跟着挥舞残影甩动 → 镜头极速甩动紧跟武器轨迹
- **格挡震动镜头**：撞击瞬间猛震 → 单次剧烈震动
- **旋转攻击镜头**：转圈打跟着转 → 镜头与角色同步旋转
- **合击同步镜头**：拉远拍两人打招 → 全景跟拍记录同步技能

### 4、特殊动作
- **翻越障碍镜头**：跟着一起翻墙 → 模拟与角色一同跃过障碍物
- **破门而入镜头**：像撞门一样推入 → 猛烈向前推进穿透破裂的门
- **受伤踉跄镜头**：歪歪扭扭晃动 → 镜头摇晃不稳模拟受伤步态
- **跳跃慢升镜头**：跳起时变慢 → 镜头跟随跳跃缓慢上升

### 5、特效动作
- **水中慢动镜头**：动作变慢像在水里 → 水下慢动作
- **魔法释放镜头**：从手发光后退看爆炸 → 从手部特写极速向后拉远
- **变身环绕镜头**：转着圈拍变身 → 快速环绕跟拍
- **终极技拉升镜头**：放大招时往后向上飞 → 极速向后上方拉升
- **胜利旋转镜头**：赢了后慢慢转圈 → 围绕主角缓慢360度环绕平移

### 6、环境互动
- **爆炸推开镜头**：气浪推镜头猛震 → 被冲击波强行推开摇晃
- **坠落跟随镜头**：跟着一起往下掉 → 保持相同速度向下坠落
- **子弹时间镜头**：人不动镜头快转 → 主体半空静止，镜头环绕移动

## 七、创意特效镜头（特殊视觉）

### 1、画面变形
- **鱼眼扭曲镜头**：边缘变成圆球 → 强烈的球形扭曲
- **微缩景观镜头**：看起来像玩具模型 → 移轴镜头效果
- **X光透视镜头**：直接看到内部 → X光透视效果
- **穿透视角镜头**：穿过墙壁看后面 → 穿透固体墙壁
- **热成像镜头**：红外线探测画面 → 热成像仪视觉

### 2、操纵时间
- **时间倒流镜头**：所有动作倒着放 → 运动轨迹完全反向
- **分身残影镜头**：动作太快留下影子 → 主体后留下半透明重影

### 3、改变画风
- **万花筒镜头**：画面对称复制 → 对称几何反射
- **水墨晕染镜头**：中国画散开效果 → 水墨晕染扩散
- **老胶片镜头**：噪点划痕闪烁 → 粗糙噪点划痕和闪烁
- **故障艺术镜头**：电视卡顿花屏 → 数字故障，色散像素撕裂
- **数据化镜头**：人变代码像素 → 分解为数字代码或像素方块

### 4、光影特效
- **镜面反射镜头**：拍镜子里画面 → 直视镜面拍反射影像
- **水面倒影镜头**：拍水洼倒影 → 对焦于水坑中带波纹扭曲的倒影
- **光影穿梭镜头**：明暗光柱穿行 → 在明亮光束与阴影间穿梭
- **星空旋转镜头**：背后星空快速转动 → 高速旋转的星空延时
- **粒子消散镜头**：人变粉末飘散 → 化为发光粒子消散

### 5、扭曲空间
- **隧道穿越镜头**：时空隧道往前飞 → 在光影隧道中极速穿梭
- **维度折叠镜头**：城市折叠起来 → 空间向上折叠弯曲
