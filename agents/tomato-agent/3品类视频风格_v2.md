# 3品类 × 3-5种视频提示词格式

---

## 🏠 品类一：家居日用品
**风格调性**：干净、实用、生活感
**核心规则**：不真人出镜，不尬夸，只看效果

### 格式A：场景效果快切型
```
[0-2s] 场景痛点特写（脏/乱/湿），快切，无人物正脸
[2-5s] 产品快速介入→问题解决，局部手部入镜即可
[5-8s] 2-3个使用场景快切（每个1.5s）
[8-10s] 效果终态展示 + 大字幕卖点
```
🎬 适合：抹布/收纳/清洁工具

### 格式B：产品静态美拍+文字流
```
[0-10s] 产品在干净背景上360°缓慢旋转展示
[0-3s] 顶部大字：产品名
[3-6s] 小字逐行弹：卖点1/卖点2/卖点3
[6-10s] 底部标语 + 价格
```
🎬 适合：收纳箱/皂盒/置物架（外观漂亮的产品）

### 格式C：分屏对比型
```
[0-10s] 左：旧方案（脏乱差）→ 右：新方案（干净整洁）
[0-3s] 同时展示左右
[3-7s] 右侧产品介入动画
[7-10s] 全屏效果展示 + 弹幕式卖点
```
🎬 适合：清洁布/压缩袋/收纳产品

### 格式D：简单告诉型（口播+产品展示）
```
[0-3s] 产品正面居中展示，无人物
[3-7s] 字幕逐行动：功能关键词
[7-10s] 价格 + 购买诱导（轻微）
配音：AI语音读字幕即可
```
🎬 适合：低价标品（不超过$3的）

## 🪞 品类二：美妆个护工具
**风格调性**：精致、专业、有格调
**核心规则**：可以局部出镜（手/脸局部），需要效果可视化

### 格式A：使用教程型（局部出镜）
```
[0-2s] 产品特写
[2-5s] 使用前状态（素颜/未打理）
[5-8s] 产品使用过程（只拍局部：手/唇/眼）
[8-10s] 使用后效果 + 满意表情（可不露全脸）
```
🎬 适合：化妆刷/美妆蛋/睫毛夹

### 格式B：产品开箱/拆盒型
```
[0-2s] 包装盒居中
[2-5s] 开箱过程（只拍手）
[5-8s] 产品品特写+细节
[8-10s] 全套排列展示 + 价格字幕
```
🎬 适合：化妆刷套装/美容工具套装

### 格式C：动画解说型
```
[0-10s] 手绘/动画形式展示产品使用方法
[0-3s] 产品出现
[3-7s] 动画演示使用原理
[7-10s] 效果动画 + 文字
```
🎬 适合：原理型产品（微电流美容仪等）

### 格式D：对比型
```
[0-10s] 分屏或快切
左侧：用手/不用产品的对比
右侧：普通工具vs这款工具的效果对比
```
🎬 适合：粉扑/美妆蛋/睫毛夹

## 🍳 品类三：厨房用品/小家电
**风格调性**：诱人、便利、生活气息
**核心规则**：只拍手和食物，不拍人脸

### 格式A：食物制作过程型
```
[0-2s] 食材准备特写
[2-6s] 产品操作过程（只拍手+食材）
[6-8s] 成品展示
[8-10s] 产品+成品的定妆照 + 卖点文字
```
🎬 适合：切菜器/冰格/沥水架（能看到使用效果的产品）

### 格式B：产品功能特写型
```
[0-3s] 产品放桌上，慢镜头旋转展示
[3-7s] 功能演示（手部操作，不露脸）
[7-10s] 效果特写 + 标签式卖点
```
🎬 适合：绞肉机/封口机/保鲜盒

### 格式C：Step-by-Step流程型
```
[0-2s] 问题场景（食材难处理）
[2-5s] 使用产品处理
[5-8s] 处理完成
[8-10s] 最终效果 + 字幕
```
🎬 适合：多功能厨房工具

### 格式D：静物排列+文字冲击
```
[0-10s] 产品在砧板/台面上排列
[0-3s] 大字闪现：产品名
[3-7s] 卖点逐行弹出（配合叮音效）
[7-10s] 价格+库存
```
🎬 适合：小工具类（削皮器/刮皮刀等）

---

## 🎥 通用原则（所有品类适用）

1. ❌ **不真人出镜正脸**（除非是美妆类局部）
2. ❌ **不尬夸/不营销语气**（口语化自然）
3. ✅ **字幕后期加，不硬编码**
4. ✅ **留配音空间** — AI语音/配乐即可
5. ✅ **10秒内解决** — 不要信息过载
6. ✅ **干净背景/自然光**
