## 3. 🔄 即梦(Seedance 2.0) API集成方案

### 3.1 当前流程缺陷

```
天赐手动登录即梦 → 复制prompt → 生成视频 → 下载 → 放源视频目录
                       ↑ 人力瓶颈 🔴
```

当前所有TOP20源视频生成都需要天赐手动在Seedance即梦操作。**没有自动化API**。

### 3.2 Seedance 即梦 API 调研（2026-05-14状态）

根据公开信息，即梦(Seedance)目前情况：

| 方式 | 可用性 | 说明 |
|:----|:-----:|:-----|
| **官方OpenAPI** | ❌ | 字节跳动Seedance至今未公开API |
| **Seedance即梦网页版** | ✅ | 用户手动操作，需登录 |
| **Seedance App** | ✅ | iOS/Android App生成 |
| **第三方代理API** | ⚠️ | 非官方，不稳定，有封号风险 |

**结论：截至目前Seedance/即梦仍无公开API，源视频生成需天赐手动操作。**

### 3.3 建议的半自动工作流程（降低天赐负担）

```
Step 1: 生菜引擎生成V5 prompt → 输出到桌面JSON
         ↓
Step 2: 天赐复制prompt到即梦 → 生成15秒视频 → 下载
         ↓
Step 3: 源视频放 ~/Desktop/源视频/{产品名}.mp4
         ↓
Step 4: 玉米V8自动扫描 → 6国混剪 → 输出到已处理TK视频_v8/
```

### 3.4 批量生成建议批次

建议天赐按品类分批操作，每次5个：

| 批次 | 品类 | 产品数 | 估计耗时 |
|:---|:-----|:-----:|:------:|
| 🅰 | 🪞 美妆 (1-5) | 5个 | ~30分钟 (即梦生成+下载) |
| 🅱 | 🪞 美妆 (6-10) | 5个 | ~30分钟 |
| 🅲 | 🏠 家居 (11-14) + 🍳 厨房(15) | 5个 | ~30分钟 |
| 🅳 | 🍳 厨房 (16-20) | 5个 | ~30分钟 |

总计：~2小时 分4批完成

### 3.6 即梦生成的注意事项（根据5/13经验）

1. **商品一致性**：V5 prompt已强制注入一致性规则，但生成后仍需人工检查
2. **15秒时长**：即梦支持15秒生成，GEN4.5最高10秒。使用Seedance 2.0
3. **竖屏**：必须选9:16，否则玉米需要做横→竖转换
4. **无水印**：Seedance本版已无水印logo
5. **自带音频**：即梦自产视频含音效，管线会选择替换为TTS+BGM
