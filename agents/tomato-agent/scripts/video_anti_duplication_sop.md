# 🥒 多国视频防重SOP（苦瓜风控 → 玉米视频管线）

## 原则
5国视频不能一模一样被TK检测到，但内容质量不能降。**微调画帧，不改核心内容**。

## 5层防重技术

### ① 画帧微调（像素层）
| 技术 | 方法 | 调整范围 |
|------|------|---------|
| 帧偏移 | 视频整体延迟±2~5帧 | 不影响视听 |
| 颜色矩阵微调 | RGB通道各±2~5 | 肉眼难辨 |
| 微噪点层 | 叠加透明度0.5~1%的噪点 | 抗哈希检测 |
| 亮度微调 | 整体±1~3% | 几乎无感 |

### ② 速度微调
| 参数 | 说明 |
|------|------|
| 播放速度 | 5国各微调0.98x~1.02x（不影响听觉） |
| 字幕出现时间 | 错开±0.1~0.3秒 |
| 转场时长 | 微调0.05~0.15秒 |

### ③ 排版与布局
| 元素 | 防重方法 |
|------|---------|
| 字幕Y轴位置 | 5国各微调±5~15像素 |
| 字幕字体大小 | ±1~3px差异 |
| BGM渐入渐出时长 | ±0.1~0.3秒 |
| 产品展示区域 | 裁剪边距±2~5像素 |

### ④ 音频指纹差异化
| 技术 | 方法 |
|------|------|
| TTS语速 | 各国家语速微调±2% |
| BGM音量 | 各版本±1~3%差异 |
| 等化器（EQ） | 各版本EQ微调（高/中/低频±1dB） |

### ⑤ 元数据层
| 项目 | 方法 |
|------|------|
| 编码参数 | 各版本使用不同crf值（18~23浮动） |
| 分辨率 | 保持1080p但微小裁剪偏移±2px |
| 文件名 | 不同命名规则 |
| 创建日期 | 不同文件时间戳 |

## 各国基准配置模板
```
TH: 速度+0.5% | 亮度+2% | RGB(+2,0,-1) | 字幕Y=1820 | CRF=20
MY: 速度-0.3% | 亮度-1% | RGB(-1,+2,0) | 字幕Y=1815 | CRF=19
VN: 速度+0.8% | 亮度+3% | RGB(0,-2,+1) | 字幕Y=1825 | CRF=21
PH: 速度-0.5% | 亮度+0% | RGB(+1,+1,-2) | 字幕Y=1818 | CRF=20
SG: 速度+0.0% | 亮度-2% | RGB(-2,0,+2) | 字幕Y=1822 | CRF=18
```

## 集成到composer_final.py
在渲染5国版本时，对每个国家版本应用以上微调参数。
核心逻辑：同一个源视频 → 5个不同的渲染参数 → 5个指纹不同的输出。

# 🥬 选品上架防重SOP（苦瓜风控 → 生菜文案 → 番茄选品）

## 原则
15个店铺(5国×3品类)，同一产品在不同店铺的商品页必须差异化，防止TK查重封店。

## ① 标题防重（5国不同）
| 国家 | 标题策略 | 关键词差异 |
|------|---------|-----------|
| TH | 泰语加流行emoji🌺🔥，后缀用ของแท้ | 本土化搜索词 |
| MY | 马来语+英语混写，马来文优先 | 本土词根不同 |
| VN | 越南语音调词，加xu hướng(趋势) | 声调语气不同 |
| PH | 他加禄语+英语，用tagalog语气 | 地区俚语不同 |
| SG | 英文为主，简洁，加✅官方正品 | 语法结构不同 |

**同一品类的不同店铺，标题关键词排列顺序调换**：
- 店1：核心词+场景词+卖点词
- 店2：卖点词+核心词+场景词
- 店3：场景词+卖点词+核心词

## ② 商品图防重
| 技术 | 方法 | 说明 |
|------|------|------|
| 主图顺序调换 | 同一套5张主图各国排列组合不同 | 最简方案 |
| 微裁切 | 每图±5~10px裁切偏移 | 抗图库检测 |
| 颜色滤镜 | 各国家加微弱的暖/冷/自然色调叠加 | 与视频防重一致 |
| 水印位置 | 各国水印坐标微调±5px | 不需水印则忽略 |
| 背景处理 | 产品图背景虚化强度±5% | 细节差异化 |

## ③ 详情页防重
- 5国详情页排版模块顺序不同（规格/物流/售后调换顺序）
- 措辞：同义句改写（如"7天退货"→"一周内退换"）
- 表情符号组合不同（🇹🇭🔥 vs 🇲🇾💥 vs 🇻🇳✨）

## ④ 定价策略
- 各国家定价基准不同（按汇率+竞争环境）
- 同一品类不同店铺价格差异化±3~5%避免比价被封

## ⑤ SKU编码防重
- 同一产品在不同店铺使用不同的SKU编码规则
- 避免平台通过SKU编码关联店铺

## 执行流程
1. 🍅番茄选品确定产品 → 基础素材（5张图+核心卖点）
2. 🥬生菜生成5国标题+描述 → 按各国策略差异化
3. 🥒苦瓜审核防重参数 → 确认无明显规律
4. 妙手ERP上架 → 不同店铺不同时间错开上架
