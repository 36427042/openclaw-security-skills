## 三、推荐方案：混合流水线（FFmpeg本地脚本 + 真人配音 + 选配BGM）

### 为什么不是纯工具方案？

| 工具 | 致命缺点 |
|------|---------|
| **纯简创/VEED/Rask** | 全部用AI TTS配音，**不满足"真人配音"要求** |
| **纯CapCut** | 批量自动化困难，真人配音导入繁琐 |
| **纯FFmpeg** | 字幕翻译和配音生成需要外部API |

### 推荐架构

```
┌─────────────┐     ┌──────────────┐     ┌────────────────┐
│  原始视频    │────▶│  FFmpeg拆帧   │────▶│  字幕生成      │
│  双头眉刷.mp4 │     │  +语音提取    │     │  (本地翻译脚本) │
└─────────────┘     └──────────────┘     └───────┬────────┘
                                                  │
                    ┌──────────────────┐          │
                    │  真人配音         │◀─────────┘
                    │  Fiverr/Upwork  │ 
                    │  当地20岁配音演员 │
                    └────────┬─────────┘
                              │
                    ┌─────────▼────────┐
                    │  FFmpeg合成      │
                    │  画面+字幕+配音  │
                    │  +BGM            │
                    └─────────┬────────┘
                              │
                    ┌─────────▼────────┐
                    │  5个最终视频输出  │
                    │  TH/VN/ID/MY/PH  │
                    └──────────────────┘
```

### 具体推荐步骤

#### Phase 1: 字幕准备（自动化）
1. 写5个语言的话术SRT字幕文件（从CSV话术中提取）
2. 每个语言·1个SRT，时间对齐原始视频

#### Phase 2: 真人配音（半自动化）
**推荐渠道对比**：

| 渠道 | 获取速度 | 质量 | 价格 | 推荐度 |
|------|---------|------|------|--------|
| **Fiverr** | 24-48h | ⭐⭐⭐⭐⭐ | $5-15/条 | ⭐⭐⭐⭐⭐ |
| **Upwork** | 24-72h | ⭐⭐⭐⭐⭐ | $10-20/条 | ⭐⭐⭐⭐ |
| **Voice123** | 24-48h | ⭐⭐⭐⭐⭐ | $20-50/条 | ⭐⭐⭐ |
| **Bunny Studio** | 12-24h | ⭐⭐⭐⭐ | $15-30/条 | ⭐⭐⭐⭐ |

**推荐的Fiverr卖家风格**：
- 泰语：找"Natural Thai female voice， youthful， 20s"
- 越南语："Giọng trẻ trung， tự nhiên， giọng miền Bắc"
- 印尼语："Suara natural anak muda Indonesia"
- 马来语："Suara natural anak muda Malaysia"
- 菲律宾语："Natural Tagalog with youth vibe"

#### Phase 3: BGM选择（半自动化）
- 每国选1-2首当地流行风格的免版权BGM
- 来源：YouTube Audio Library / Pixabay（免费）
- 标注在脚本配置中自动匹配

#### Phase 4: 自动化合成（全自动脚本）
用一个FFmpeg脚本实现：
1. 读入原始视频画面
2. 硬编码当地语言字幕（burn-in）
3. 替换音频为真人配音轨
4. 叠加当地BGM（混音）
5. 输出最终视频

## 四、快速测试脚本

以下为测试用的FFmpeg合成脚本，可以直接在本地测试1国版本。

### 测试步骤说明

由于此测试需要**真实的音频素材**（真人配音+当地BGM），脚本设计了：
1. **使用已有的简创生成视频的画面帧** — 已验证可用
2. **字幕测试** — 用FFmpeg burn-in字幕验证
3. **配音测试** — 留接口，导入真人配音后合成
4. **BGM测试** — 留接口，导入BGM后混音

### 测试脚本

```bash
#!/bin/bash
# 双头眉刷 - 5国视频自动化合成脚本
# 使用方法: bash multi_lang_video.sh [语言代码]
# 语言代码: TH VN ID MY PH

LANG_CODE=${1:-TH}

# 配置
INPUT_VIDEO="$HOME/Desktop/双头眉刷.mp4"
OUTPUT_DIR="$HOME/Desktop/5国视频测试"
SRC_VIDEO="$HOME/Desktop/简创5国视频/双头眉刷_${LANG_CODE}.mp4"

# 话术CSV中的文本（各语言）
declare -A TEXTS
TEXTS[新加坡]="画眉总是画不对称？试试这个双头设计，一头梳理，一头塑形。你看，效果真不错"
TEXTS[泰国]="画眉总是画不对称？试试这个双头设计，一头梳理，一头塑形。你看，效果真不错 ค่ะ"
TEXTS[菲律宾]="画眉总是画不对称？试试这个双头设计，一头梳理，一头塑形。你看，效果真不错 Sis"
TEXTS[越南]="画眉总是画不对称？试试这个双头设计，一头梳理，一头塑形。你看，效果真不错 các bạn ơi"
TEXTS[马来西亚]="画眉总是画不对称？试试这个双头设计，一头梳理，一头塑形。你看，效果真不错 korang"

mkdir -p "$OUTPUT_DIR"

echo "=== 生成 $LANG_CODE 字幕SRT ==="
cat > "$OUTPUT_DIR/${LANG_CODE}.srt" << SRTEOF
1
00:00:00,000 --> 00:00:03,000
$(echo "${TEXTS[$LANG_CODE]}" | cut -c1-15)...
2
00:00:03,000 --> 00:00:08,000
试试这个双头设计
一头梳理，一头塑形
3
00:00:08,000 --> 00:00:10,000
你看，效果真不错
SRTEOF

echo "=== 合成 $LANG_CODE 版本 ==="
# 从简创视频提取画面（作为高质量画面源）
# 硬编码字幕
ffmpeg -i "$SRC_VIDEO" \
  -vf "subtitles=$OUTPUT_DIR/$LANG_CODE.srt:force_style='FontName=Arial,FontSize=18,PrimaryCol=&H00FFFFFF,OutlineCol=&H00000000,BorderStyle=3,Outline=1,MarginV=40'" \
  -c:a copy \
  -y "$OUTPUT_DIR/双头眉刷_${LANG_CODE}_subtitled.mp4" 2>&1 | tail -5

echo ""
echo "=== 输出文件 ==="
ls -la "$OUTPUT_DIR/双头眉刷_${LANG_CODE}_subtitled.mp4"
echo "=== 完成 $LANG_CODE 版本 ==="
```
