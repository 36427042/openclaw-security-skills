# Zopia + OpenClaw = 一人AI短剧公司（天赐提供 2026-05-10 01:37）

## 背景
- AI短剧是2026年最火行业之一
- 抖音《斩仙台真人AI版》12.4亿播放
- 浙江卫视《中国传说・白蛇》国内首部AI短剧
- 120分钟中等质量真人短剧 = 15人×1月
- 传统方式已告别个人/小团队

## 但两件事改变了局面

### 变化1：短视频平台批量涌现真人AI短剧
- 角色像爱豆一样好看
- 剧情让人心痒痒
- 条条爆火
- 观众不再只满足画面流畅 → 要求更高级的人物和剧情设计

### 变化2：小龙虾（OpenClaw）的出现
- 可以操控Agent的Agent
- 告诉它做AI短剧 → 它自动调兵遣将干活

## 完整工作流

### Step 1：获取Skills
- Zopia官网（右上角小龙虾入口）→ 点击"我是代理人"
- 找到AI短剧Skills → 点击复制
- Skills = 口服版武功秘籍，吃了就能跳过学习直接习得神功

### Step 2：喂给OpenClaw
- 打开云端龙虾平台（飞书）
- 把Skills发给他 → 自行学习

### Step 3：注入Token
- 回到Zopia → 点击"我是人类"
- 下滑找到获取API令牌 → 生成新Token → 复制喂给龙虾

### Step 4：传达制作要求
- 告诉需求：如"生成一个真人丧尸校园题材短剧"
- OpenClaw自动撰写剧本 + 分镜 + 人设图

### Step 5：按顺序生成
- OpenClaw按步骤一步步生成
- 完成后返回项目链接

### Step 6：Zopia内修改完善
- 角色形象偏差可对话修改（校服款式/颜色等）
- 确认人物形象后生成分镜
- 不满意的画面可单独修改
- 符合预期就直接进入视频生成

### 核心优势
- 效率顶几十人团队
- 标准AI短剧制作流程
- 前：角色设定图 + 场景资产图
- 中：角色放入场景 + 交互对话
- 后：内置自动剪辑功能
- 派活后干别的，回来直接验收成果
