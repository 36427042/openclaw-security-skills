### 标题模板 1 — ครีมบำรุงผิวหน้า + ชุ่มชื้น（保湿面霜）

**变体A：**
```
ครีมบำรุงผิวหน้า ชุ่มชื้น ฟื้นบำรุง ผิวเนียนนุ่ม สำหรับผิวมัน/ผิวแห้ง ใช้ประจำวัน เนื้อบางเบา ซึมไว
```

**变体B（微调词序）：**
```
เนื้อบางเบา ซึมไว ครีมบำรุงผิวหน้า ชุ่มชื้น ฟื้นบำรุงผิว สำหรับผิวแห้งผิวมัน ใช้ประจำวัน ผิวเนียนนุ่ม
```

**描述关键词池（组合使用）：**
- ครีมบำรุงผิวหน้า（面霜）, ชุ่มชื้น（保湿）, ฟื้นบำรุง（滋养）, ผิวเนียนนุ่ม（柔滑）
- เนื้อบางเบา（轻薄质地）, ซึมไว（快速吸收）, ใช้ประจำวัน（日常使用）
- สำหรับผิวแห้ง/ผิวมัน/ผิวผสม（干性/油性/混合性肌肤）
- ปราศจากน้ำหอม（无香精）, ไม่มีสารกันเสีย（无防腐剂）

## 🔄 选品上架防重策略

### 同类目/同店铺微调方法

| 方法 | 举例 | 说明 |
|:----|:-----|:-----|
| ① 词序调换 | "保湿霜干皮" → "干皮保湿霜" | 用户搜索逻辑不同即可 |
| ② 同义词替换 | "cream" → "moisturizer" → "hydrating cream" | 用同品类关键词池互换 |
| ③ 长尾词交替 | 去掉「修护」换成「嫩肤」 | 避免系统判定重复 |
| ④ 前后缀变化 | 加前缀「超值装」/「明星单品」/「日常必备」 | 每个listing加不同前缀 |
| ⑤ 标点符号 | 空格/逗号/竖线交替使用 | 如「|」vs「,」vs「·」 |
| ⑥ 缩写vs全称 | "SPF50" vs "กันแดด SPF 50" vs "防晒值50" | 五个listing全不同 |

### 建议轮换顺序

```
同一产品 → 5个变体标题 → 分配到5个不同站店
每周轮换 → A换B换C换D换E（减少平台查重）
```
