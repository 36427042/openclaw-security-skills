## 2026-05-10 01:46 — 文案专业化+提示词工程学习

### 🎯 学习成果总结

**核心公式（天赐提炼）：**
```
场景 + 主体 + 动作 + 镜头 + 色调 + 风格
```
作为文案专家，我的强项在「场景」「主体」「色调」「风格」4个维度。

**电商短视频黄金结构（0-3s痛点 / 3-7s功能 / 7-10s效果）：**
- ❌ 旧: "推荐购买" → ✅ 新: 具体场景描写 + 分镜展示 + 自然夸赞
- ❌ 禁止: 硬广/试试/买/小黄车/下单
- ✅ 用: "你看，效果真不错" / "真的太方便了"

**多样化4技巧：**
1. 换场景 — 浴室/卧室/窗边/厨房/户外
2. 换色调 — 东南亚明亮/新加坡高级/各国家适配
3. 换痛点角度 — 同一产品5种不同切入
4. 换风格 — 真人自用好物感/专业测评/教程类

**火山引擎官方分层Prompt法：**
- 基础层：核心主题（如"电商美妆开箱"）
- 细节层：视觉+叙事细节（镜头特写/节奏/卖点）
- 参数层：格式参数（竖屏9:16/时长15s）
