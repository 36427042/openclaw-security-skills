| 3-7s | **功能展示**——演员把手机放进防水袋，封好口夹紧。然后走进洗手间/水盆前，把袋子沉入水中，隔着袋子操作手机 | "套上这个防水袋，封口一夹，直接扔水里都没问题。而且它薄的——在水里也能触屏，还能拍照。" | 封口一夹 / 直接扔水里 / 水下也能触屏拍照 |
| 7-10s | **自然收尾**——演员把袋子挂在脖子上，拍拍袋子，露出放心轻松的表情 | "挂脖子上就行，稳稳的，怎么跑怎么跳都不会掉。在家备一个，出去玩就不用愁了。三块钱，买个安心。" | 挂脖设计 / 怎么玩都不掉 / 仅3块 |

### 📐 拍摄指导

- **景别**: 中景→特写（入水/操作）→近景
- **关键动作**: 封口步骤不要省略——这是观众最关心的问题（到底会不会进水）
- **水池展示**: 可以用透明玻璃碗装水，把袋子沉进去，镜头从碗侧面拍，看得更清楚
- **安全性**: 手机提前套两层保鲜膜防万一

# 📋 拍摄总建议

## 🎯 核心原则
1. **不要念广告词**——要像朋友分享好用的东西一样说话
2. **痛点和产品要实拍**——旧抹布、干皮、素眼、塌睫毛、变质肉——都要实拍
3. **一镜到底/长镜头优先**——减少拼接感，更有真实感
4. **每个产品拍2-3条**——不同角度/不同开场词，方便后期选片

## 🎬 演员指导
- 表情放松，不要对着镜头演讲
- 可以有多余的小动作（摸头发、整理衣服等），更自然
- 台词可以自己改成更顺嘴的说法——大意不要变

## 🔧 装备建议
- 手机/相机固定在三脚架上
- 自然光优先，不够再加补光灯
- 录音用无线小蜜蜂（领夹麦），后期声音清晰很重要
