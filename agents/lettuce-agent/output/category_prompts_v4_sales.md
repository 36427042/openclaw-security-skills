## 📐 使用说明

### 粘贴到Runway Gen-4
1. 复制每个 **🔗 English Prompt** 整段到Runway Text-to-Video
2. 选中 **Gen-4** 模型
3. 保持 **9:16** 比例
4. 如有Reference Image选项，优先上传产品白底图

### V3 → V4 核心升级对照

| 维度 | V3 (淘汰) | V4 (当前) |
|:------|:-----------|:----------|
| 产品位置 | "场景的一部分" | **第一帧就是产品** |
| 背景 | 窗帘/植物/架子/花瓶 | 纯白底/纯木纹/无干扰 |
| 功能演示 | ❌ 无 | ✅ 人手操作/效果对比/收纳展示 |
| 卖点传达 | 靠氛围暗示 | 靠功能演示 |
| 收尾 | 氛围淡出 | 产品仍在画面收尾 |
| 非产品内容 | 家具/窗帘/装饰品 | 只保留必须的：手/产品/收纳物 |
