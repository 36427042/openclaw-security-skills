## ⭐ 第二阶段进阶成果（2026-05-11 05:55-07:00 深度学习）

### 🏆 核心突破：SSML标签可完全通过边缘TTS文本传递
- **发现**：Azure后端可以解析被 `xml.sax.saxutils.escape()` 转义的SSML标签(`&lt;...&gt;`)
- **这意味着**：不用改edge-tts源码，直接在text参数里写SSML全部可用！

### 已确认可用的SSML标签
| 标签 | 用途 | TikTok应用 |
|------|------|-----------|
| `<break>` | 停顿控制(200ms/500ms/1000ms) | 开场后、价格前、卖点前 |
| `<emphasis>` | 关键词强调(strong/moderate) | "折扣""限量""免费" |
| `<prosody>` | 局部语速/音高变化(嵌套) | 大段中局部加速/减速 |
| `<phoneme>` | 精确发音(IPA音标) | 品牌名/专业术语校正 |
| `<say-as>` | 数字读法(cardinal/digits) | "999"读"九-九-九" |
| `<sub>` | 缩写替换 | "TL"→"เท่านั้นพอ" |
| `<mstts:express-as>` | 情感语调 **⭐核心** | 开场cheerful/展示friendly/结尾excited |
| `<mstts:silence>` | 头尾静音 | 剪辑保护 |
| `<lang>` | 多语言切换 | 泰语中读英语品牌 |
| `<p>`/`<s>` | 段落分割 | 长文案分短句 |
