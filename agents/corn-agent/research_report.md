**研究员**: 🌽玉米（视频制作专家）

## 一、关键发现（8条）

### 发现1：美妆个护在东南亚TikTok全线霸榜
美妆个护是TikTok Shop东南亚市场的**第一大品类**，在泰国（18.07%）、印尼（22.36%）、越南（22.48%）、菲律宾（18.33%）、马来西亚（21.64%）的销售占比均居首位。防水眉笔在泰国周销8.87万件，免胶假睫毛在越南双产品上榜。

### 发现2：TikTok视频去重已进入"感知指纹+AI指纹"双检测时代
TikTok不仅用MD5校验，更运行**感知哈希（pHash）+ Chromaprint音频指纹**。感知哈希提取视频帧的DCT低频特征生成64bit指纹，仅改几帧、改色彩无法绕过。AI驱动指纹召回率67% > 感知哈希的25%。

### 发现3：5国用户偏好差异显著，需要差异化视频方案
- **泰国**: 看重性价比，喜欢高对比度妆容展示，BGM爱T-pop和emotional R&B
- **马来西亚**: 穆斯林时尚重镇，偏好温和自然妆容，BGM爱慢速翻唱和宗教情感音乐
- **越南**: 底妆要求极高（热带出油），妆效对比类视频火爆，BGM爱越南版华语流行
- **菲律宾**: OPM（菲律宾原创音乐）是TikTok爆款引擎，妆容倾向明亮水光肌
- **新加坡**: 消费力最强，偏好极简ins风，中英文混合BGM

### 发现4：TikTok音频指纹依靠Chromaprint算法，音调偏移>0.5%即有效绕过
Chromaprint将音频转为色谱图→特征提取，对音调偏移>0.5%敏感。音量变化无效（被归一化），但0.6%的音调偏移+时间拉伸可突破音频匹配。

### 发现5：去重不是单操作而是"组合拳"
6层防重需同时攻击：MD5哈希层、感知哈希视频指纹层、音频指纹层、元数据层、帧序列层、字幕/贴纸层。单层操作必然被防。

### 发现6：每个国家有独特的BGM Genre偏好
- 🇹🇭泰国: T-pop + 情感R&B + 慢速hits（sped-up版本也流行）
- 🇲🇾马来西亚: 马来流行 + nasheed型宗教BGM + 东南亚fusion
- 🇻🇳越南: V-pop + 越南语翻唱中文歌 + EDM remix
- 🇵🇭菲律宾: OPM + 欧美TOP 40 + 舞曲mashup
- 🇸🇬新加坡: 华语流行 + 欧美主流 + K-pop

### 发现7：5国客单价差异决定了视频文案策略
菲律宾客单价仅$1-2（极致低价导向），泰国/马/越$4-6（性价比），新加坡/印尼稍高。视频文案必须匹配当地消费者的价格敏感度。

### 发现8：简创AIGC流水线+GEP引擎构成"成功闭环"
当前流水线已整合GEP（General Evolution Protocol）自进化引擎，每次视频生成的成功/失败都被记录。故障模式可以自动学习并避免重复，但尚未系统化优化去重策略。

### 2.2 TikTok 6层防重技术深度解析

#### 第一层：MD5/Cryptographic Hashing — 最基础层
**原理**: 文件字节级哈希，改1字节哈希全变。
**绕过**: 任何剪辑操作（裁剪1帧、加1个音轨、修改码率）都会自动绕开。
**当前流水线**: ✅ 简创AIGC渲染自带新编码，MD5已不同。
**⚠️ 仅靠MD5不足**: TikTok已经不依赖MD5做主去重。

#### 第二层：Perceptual Hashing（感知哈希）— 去重核心战场
**TikTok的实现**（业界公开资料推导）:
1. 每隔1-2秒抽取1帧
2. 缩小至32x32灰度图（去掉颜色信息）
3. DCT变换 → 保留低频8x8区域 → 生成64bit指纹
4. 汉明距离 < 5=相同内容，5-10=疑似，11+=不同

**有效绕过参数**:
- 裁剪（crop）：仅7-8px裁剪就能改变帧结构 → `ffmpeg -i input.mp4 -vf "crop=iw-8:ih-8:4:4" output.mp4`
- 噪声叠加：噪声强度8+可破坏低频 → `ffmpeg -i input.mp4 -vf "noise=alls=8:allf=t" output.mp4`
- 亮度微调：>1%亮度改变可使多个位翻转
- ❌ 颜色调整基本无效（灰度化去色）
- ❌ 单纯重编码无效（画面内容不变）

**当前流水线现状**: ❌ **未做**。流水线直接调用简创AIGC渲染，未做帧级别的感知哈希绕过。

#### 第三层：Audio Fingerprinting（Chromaprint）— 音频防重
**原理**: 
1. 音频转为单声道 - 11025Hz - 归一化音量
2. STFT频谱分析 → 色谱图提取 → 32bit序列指纹
3. 音调偏移>0.5%可绕过

**有效参数**:
- 0.8%音调偏移：`ffmpeg -i input.mp4 -af "asetrate=44100*1.008,aresample=44100"`
- 2%速度变化+音调自适应：`ffmpeg -af "atempo=1.02"`
- 叠加背景音/自然白噪声
- ❌ 单纯更改音量无效（被归一化）
- ❌ 仅换个码率编码无效

**当前流水线现状**: ⚠️ **部分做**。简创AIGC通过更换TTS语音+本地BGM实现了部分音频去重，但TTS内容相同（只是翻译版），音色相同国家内，音频指纹仍然部分匹配。

#### 第四层：Metadata Fingerprinting — 元数据层
**原理**: 检测文件创建时间、修改时间、设备ID、编码器信息、GPS坐标等。
**绕过**: 
- 清空metadata：`-map_metadata -1`
- 修改创建时间：`-metadata creation_time=...`
- 更改编码器vendor ID

**当前流水线现状**: ⚠️ **未检查**。简创AIGC渲染输出的视频需确认是否自带metadata。

#### 第五层：Frame Sequence + Cut Detection — 帧序列层
**原理**: 检测帧序列的切点模式、关键帧分布、场景转换位置。
**绕过**:
- 抽帧+补帧：删除1-2帧并复制相邻帧插入（人眼不可察觉，帧序列变化显著）
- 局部变速：非重点过场2-3x加速
- 动态缩放：持续放大至110% / 缩小至90%，每帧像素不同

**当前流水线现状**: ❌ **未做**。当前流水线为单源视频+模板渲染，帧序列高度一致。

#### 第六层：AI Embedding（深度特征向量）— 最新前沿
**原理**: 使用神经网络提取高维特征嵌入向量。召回率67%，能检测经过重度修改的内容。
**绕过**: 需要组合多种修改（画面+音频+结构+贴纸）使embedding向量偏离。
**参考**: 学术界提出的"混合策略"——感知哈希做初筛，AI做深度分析。

**当前流水线现状**: ❌ **未对抗**。但简创AIGC的云渲染天然改变了一些底层特征。

### 2.3 GEP自进化引擎分析

当前流水线已集成GEP引擎，模式为：
1. **pre_check** — 在调用API前检查该国家/该API是否有历史失败记录
2. **post_record** — 记录成功/失败+上下文
3. **GEPNode** — 不可变进化节点，存储partner+task+problem+solution+outcome

**用GEP提升去重的设计思路**:
- 可以为每个视频版本记录"去重维度/参数/结果"作为进化节点
- 当某参数的视频被判定非原创时，GEP记录失败模式，下次自动调参
- 7个伙伴共享进化库 → 玉米的视频去重经验可被其他角色复用

## 四、素材库搭建方案

### 4.1 BGM库
**采集来源**: TikTok Creative Center → 各国家地区Trending Sounds每周抓取
**分类结构**:
```
BGM库/
├── TH/  (T-pop, R&B情感, 慢速hits)
├── MY/  (马来流行, nasheed, 东南亚fusion)
├── VN/  (V-pop, 翻唱中文, EDM remix)
├── PH/  (OPM, 欧美TOP 40)
├── SG/  (华语流行, K-pop)
└── GLOBAL/ (无版权, 通用)
```
**自动化**: 用TikTok API每周自动抓取各区域Trending Sounds Top 20，预估版权风险后入库。

### 4.2 贴纸库
- **国家特色**: 泰国金链emoji / 马来西亚清真标识 / 越南斗笠/莲花 / 菲律宾太阳/笑脸
- **功能型**: 箭头、价格标签、"NEW"、"HOT"、折扣火花、购买按钮
- **动态贴纸**: 入场动画、弹跳效果、渐隐渐现
- **存储**: 按国家/功能/颜色分类，PNG+Alpha通道

### 4.3 转效库（转场+特效）
- **硬切组**: 快闪、旋转、缩放切、定格
- **软切组**: 模糊入、闪白、擦除、VHS风格
- **音效组**: 刷声音效、咔嚓声、成功音效、弹跳音
- **国家特化**: 泰国多用彩色闪光转场 / 越南多用清晰硬切

### 4.4 空镜库（B-roll）
- **手持展示**: 不同角度握笔手持
- **刷毛特写**: 慢动作展示毛尖柔软度
- **眉部特写**: 各种眉形、不同肤色
- **上妆过程**: 不同环境光下的上妆演示
- **完成效果**: 不同国家模特模特展示（本地化需求）

## 五、5国美妆工具视频拍摄SOP

### 通用前置（所有国家）
1. **拍摄前**: 准备白色/柔和背景，自然光+补光灯，保证产品细节清晰
2. **拍摄素材**: 
   - 素颜眉部特写 x3角度(正面/左侧/右侧)
   - 双头眉刷梳头特写 x2角度
   - 刷头画眉过程(慢速+常速)
   - 完成效果 5秒稳定镜头
   - 产品独立展示(前后旋转)
3. **音频准备**:
   - 各国TTS语音生成
   - BGM匹配国家偏好
   - ASMR音效录制(刷眉声音)

## 六、可执行建议（5条）

### 建议1：在video_pipeline_v2.py中增加FFmpeg去重步骤
当前流水线缺少帧级/音频级去重预处理。建议在`gen_country_video()`前增加一个`dedup_preprocess.py`步骤，对源视频执行FFmpeg的6层组合去重（裁剪+噪声+亮度+音调偏移+抽帧+清元数据），然后再送入简创AIGC。

### 建议2：建立动态BGM库并接入GEP记录
搭建国家分类BGM库，每个视频使用不同的BGM组合。将BGM使用+去重结果记录到GEP，学习哪些BGM在不同国家被判定为"非原创"的概率最高。

### 建议3：每国家创建3个不同模板，轮换使用
当前使用单一模板（TEMPLATE_ID）。建议为每个国家创建3个差异化模板（A/B/C），按周轮换。结合GEP的pre_check，如果A模板在某国家重复被标记，自动切换到B模板。

### 建议4：引入帧序列随机化模块
开发一个随机化脚本，在导入素材前对视频应用以下操作：
- 随机裁剪量（6-10px之间）
- 随机亮度偏移（0.01-0.025之间）
- 随机抽帧位置（每25-35帧随机删1帧）
- 随机局部变速（选1-2个过场片段做1.5-2x加速）
使每次渲染的底层指纹都不同。

### 建议5：使用GEP构建"去重进化回路"
将每次视频的去重参数、平台判定结果、播放量数据写入GEP。当播放量<200时，记录为失败节点；当播放量>5000时，记录为成功节点。GEP会学习到有效的去重参数组合，未来自动推荐最优去重配置。这是一个"视频产出→数据反馈→策略优化→更好产出"的闭环进化系统。

## 七、附录：技术参考

### FFmpeg 6层去重组合命令（推荐参数）
```bash
# 组合命令：6层去重一次性执行
ffmpeg -i input.mp4 \
  -vf "crop=iw-8:ih-8:4:4,noise=alls=6:allf=t,eq=brightness=0.012" \
  -af "asetrate=44100*1.006,aresample=44100" \
  -c:v libx264 -crf 23 \
  -map_metadata -1 \
  -metadata comment="generated_$(date +%s)" \
  output.mp4
```

### GEP集成代码模板
```python
# 在video_pipeline_v2.py中新增
def dedup_preprocess(source_video, country_code, gep):
    ctx = {"country": country_code, "task": "dedup_preprocess"}
    
    # 查询GEP中该国家的最佳去重参数
    best_params = gep.pre_check("dedup_config", ctx)
    
    if best_params:
        crop_px = best_params.get("crop", 8)
        noise_lv = best_params.get("noise", 6)
        pitch = best_params.get("pitch", 1.006)
    else:
        crop_px = 8
        noise_lv = 6
        pitch = 1.006
    
    # 执行去重
    cmd = f'ffmpeg -i "{source_video}" ...crop={crop_px}...noise={noise_lv}...pitch={pitch}...'
    subprocess.run(cmd, shell=True, check=True)
    
    gep.post_record("dedup_config", ctx, "success", 
                    note=f"crop={crop_px}, noise={noise_lv}, pitch={pitch}")
```

## 研究结论

东南亚5国美妆工具短视频已进入"精细化运营"阶段。产品本身（双头眉刷）具有清晰的通用痛点价值——梳头整理眉流+刷头填充眉形，但在不同国家需要**差异化包装**：泰国打情感牌、马来西亚打诚意牌、越南打功能牌、菲律宾打价格牌。

去重方面，简单换BGM和TTS完全不够。需要主动对抗TikTok的**感知哈希+音频指纹+AI嵌入三重检测系统**，每层独立修改。当下流水线的最大缺口是**缺少FFmpeg预处理去重步骤**和**去重效果回传GEP的进化回路**。

抓住这两个缺口，执行建议1和5，东南亚5国美妆视频的通过率和播放量会有显著提升。
