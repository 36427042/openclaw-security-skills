# 通用基础规则（所有品类/国家通用）

## 一、短视频通用要求（10-15秒，3秒钩子）
- **画面**：无真人出镜、无杂乱背景，突出产品特写+使用对比，配轻音乐（无歌词）
- **文案**：极简口语化，不堆关键词（不做商品卡），不夸大、不涉功效词
- **红线**：
  - 严禁说"治疗、美白、祛斑、祛痘、消炎、瘦身"等功效词
  - 严禁用"最、第一、百分百"等绝对词
  - 严禁出现其他平台logo、水印

## 二、数字人直播通用要求（24小时循环播）
- **画面**：产品特写为主，数字人半身出镜（微笑、动作自然，无夸张表情），固定文字水印（对应国家语言"好用、便宜、方便"）
- **话术**：极简循环，无大声叫卖、无功效承诺，每段15-20秒，循环播放
- **违规禁忌**：不模仿真人实时互动、不刷评论/点击/销量；不展示违禁品（液体过量、刀片、喷雾等）
