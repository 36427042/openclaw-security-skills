#### 🔄 多样化4技巧（防重+批量出片）
1. **换场景**：同一产品不同场景（浴室→卧室→窗边→厨房）
2. **换镜头**：不同运镜方式（推近→环绕→俯拍→跟拍）
3. **换色调**：不同色彩氛围（明亮→暖色→冷调→自然）
4. **换痛点角度**：不同切入角度（使用前困扰→对比→效果展示）

这个4技巧可以和我原来的5国风格差异组合使用：
- 🇹🇭**泰**：场景鲜艳+快节奏环绕+暖色调+痛点直白
- 🇲🇾**马**：场景简约+平缓推近+温和色调+理性诉求
- 🇻🇳**越**：场景活泼+晃动真实感+鲜艳色调+痛点强烈
- 🇵🇭**菲**：家庭温馨场景+静止凝视角+暖色滤镜+情感共鸣
- 🇸🇬**新**：品质感场景+慢速推拉+冷色留白+效果数据

#### 🚫 避坑清单（5条铁律）
1. ❌ 禁止高速动作 — 画面模糊（电商产品用慢速/稳定运镜）
2. ❌ 禁止复杂多人互动 — 角色混淆（电商只拍单人/纯产品）
3. ❌ 禁止模糊/抽象词（"好看""很美"→具体到颜色/材质/光泽）
4. ❌ 禁止写实真人面部（平台拦截，用产品/手部替代）
5. ✅ 一个视频只做一件事（15s聚焦一个核心卖点）
