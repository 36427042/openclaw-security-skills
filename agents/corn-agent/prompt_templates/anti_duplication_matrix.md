## 四、总体差异化策略

### 4.1 视觉避重五原则

| 原则 | 说明 | 落地方法 |
|------|------|---------|
| **原则1：完全不同场景** | 同品类5国选5种完全不同的背景 | TH室内/MY居家/VN校园/PH户外/SG职场 |
| **原则2：色调系统隔离** | 五国分配独立的色环区域 | TH暖黄/MY暖棕/VN粉白/PH粉金/SG冷灰 |
| **原则3：运镜序列不同** | 至少前2个核心运镜不同 | 见各矩阵的"运镜核心"列 |
| **原则4：画幅裁切不同** | 字幕位置+主体构图偏移 | 各国使用不同字幕区域 |
| **原则5：文化彩蛋埋设** | 加入各国独有的视觉元素 | 地标/食物/习惯场景 |

### 4.2 同一产品5国版本画面差异速查

```
         TH         MY         VN         PH         SG
场景:  🏠空调房  🪟木窗边  ☕老咖啡  🏬大商场  🏢CBD
色调:  🌅暖金黄  🌄琥珀棕  🌸粉白调  🌺艳粉金  🌫冷灰调
速度:  🚶‍♂️中      🐢慢      🏃‍♀️快      🏃快      🚶‍♀️优雅
运镜:  🔄手持    ➡️平移    🎯Z轴    ⭕环绕    🎠弧线
字幕:  ⬇️下方    ↗️右上    ↙️左下    ⬇️中大    ↙️极小
BGM:   🎵泰流    🎶马传    🎧现独    🎤OPM    🎹Jazz
```

### 4.3 多版本生成防重 Checklist

**生成前检查：**
- [ ] 5国场景互不相同（无一重复场景词）
- [ ] 5国色调描述不同（暖黄/暖棕/粉白/粉金/冷灰互斥）
- [ ] 5国运镜序列的前2个镜头互不相同
- [ ] 5国的痛点切入点不同（汗湿/暗沉/卡粉/出油/毛孔）
- [ ] 5国包含各自的文化地标/元素彩蛋
- [ ] BGM建议指向不同风格/乐器
- [ ] 字幕位置指定不同的屏幕区域

**生成后检查（肉眼对比5个视频）：**
- [ ] 5个视频相互看不出是同一个prompt配方
- [ ] 同一个产品在不同视频中不会触发相似帧检测
- [ ] 背景色/主色调无重叠色环区域
- [ ] 主体在画面中的构图比例/位置不同

## 五、紧急替换方案

如果某个版本因色调/场景与另一国过于相似：

| 冲突组合 | 问题 | 修复方案 |
|---------|------|---------|
| TH↔MY色调近似 | 都偏暖 | TH增强金色饱和度 (Gold Saturation +30%)，MY添加传统纹理(Traditional Batik Pattern Overlay) |
| VN↔SG偏亮白 | 都偏白调 | VN改为粉彩白(Pastel White+Pink)，SG改为工业灰白(Industrial White+Steel Blue) |
| PH↔TH场景冲突 | 户外炎热 | PH保持高饱和商场,TH改室内冷气房+暖色光 |
| 所有版本运镜单一 | 都推拉 | 按矩阵分配：TH=手持/MY=平移/VN=Z轴/PH=环绕/SG=弧线 |
