# 🌽 玉米·正确方向指南

## 视频分析结论（土豆已分析）

天赐发来的源视频（超细纤维抹布）存在以下问题：
1. ❌ 硬编码了马来文字幕 → 6国版本无法复用
2. ❌ 缺少7-10s"自然夸赞"环节
3. ❌ 0-3s痛点铺垫不足

## 正确的SOP方向

**10秒结构（严格遵循）：**
- 0-3s: 痛点展示（水渍难干/抹布发臭）
- 3-7s: 功能展示（一擦即干/吸水测试）
- 7-10s: 自然夸赞（干净清爽/满意表情/家人认可）

**核心原则：**
1. ✅ **不硬编码字幕** — 字幕后期加
2. ✅ **留配音空间** — 6国版本需要不同语音
3. ✅ **口语化、自然、无营销引导词**
4. ✅ **每个产品不重复话术**
