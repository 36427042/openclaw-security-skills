| 节点 | 时机 | 审什么 | 谁审 | 处理方式 |
|------|------|--------|------|----------|
| P0 | 选品导入后 | 成分/资质/供应商风险 | 🥒苦瓜（自动） | 高风险禁入 | 
| P1 | 文案产出后 | 5国违禁词/功效宣称 | 🥒苦瓜（自动） | 门槛词自动替换/红词退回 |

## 二、文案审查流程（自动化）

### 2.1 输入
- 文案文件（CSV/JSON/纯文本）
- 目标国家（TH/MY/VN/PH/SG）
- 产品类目（美妆/工具）

### 2.2 逐项检查

```
输入文案
  ↓
Step 1: 违禁词扫描 → 匹配违禁词库(500+词)
  ↓
Step 2: 功效宣称检测 → 是否含无数据支撑的功效宣称
  ↓
Step 3: 医疗暗示检测 → "治疗""治愈""医生推荐"等
  ↓
Step 4: 比较级/绝对词检测 → "第一""最好""唯一"
  ↓
Step 5: 国家特殊规则 → 泰国FDA/印尼清真/越南新规
  ↓
输出风险报告
```

### 2.3 每项检测细则

**Step 1 - 违禁词扫描**
```
输入: 文案text + 国家code
算法: 正则匹配 + 模糊匹配（容忍emoji/空格变体）
输出: [{word, line, risk_level, suggestion}]
评分: 每个HIGH词扣10分, MEDIUM扣5分, LOW扣1分
```

**Step 2 - 功效宣称检测**
```
HIGH风险宣称（扣15分）:
  - 美白/祛斑/防晒（无特证）
  - 治疗脱发/生发
  - 排毒/抗皱逆龄
MEDIUM风险宣称（扣8分）:
  - 祛痘/控油（无数据）
  - 修复/滋养（无检测报告）
  - 敏感肌适用（无测试）
```

**Step 3 - 医疗暗示检测**
```
匹配模式:
  - "医生推荐"/"医院同款"/"医用级"
  - "治疗效果"/"治愈"/"根治"
  - "处方级"/"手术级"
  - 使用白大褂/听诊器场景描述
处理: 直接标记HIGH, 不可自动替换, 退回修改
```

**Step 4 - 比较级/绝对词**
```
绝对禁止:
  - "第一"/"最好"/"最便宜"/"唯一"
  - "百分百"/"100%有效"/"保证效果"
  - "无任何人能比"
处理: 建议替换为"口碑佳"/"持续复购"等合规词
```

### 2.4 风险分计算公式

```
总分 = 100分起算
扣分 = Σ(违禁词) + Σ(功效宣称) + Σ(医疗暗示) + Σ(绝对词)

结果:
  ≥ 80分 → ✅ 通过（自动合规）
  60-79分 → ⚠️ 预警（需手动复审）
  < 60分 → ❌ 退回（修改后重审）
```

## 三、视频审查流程（自动化）

### 3.1 关键帧检查点

| 检查点 | 检测内容 | 技术方式 | 风险等级 |
|--------|----------|----------|----------|
| 封面帧 | 违规文字/夸大宣称 | OCR扫描 | HIGH |
| 人物帧 | 是否穿白大褂/医生制服 | 图像识别 | HIGH |
| 产品展示帧 | 产品标签是否合规 | OCR+图像 | MEDIUM |
| 对比帧 | 前后对比图 | 图像比对 | HIGH |
| 字幕帧 | 是否含违禁词 | OCR+文本 | MEDIUM |
| 价格帧 | 价格欺诈/虚假原价 | OCR | MEDIUM |

### 3.2 字幕文本扫描
```
输入: 视频SRT字幕文件（如无则语音转文字）
检测: 调用文案审查流程（同上）
特殊规则:
  - 泰语视频: 额外检测"อย."认证暗示
  - 马来语视频: 额外检测清真认证暗示
  - 越南语视频: 检测"Đây là quảng cáo"标注
```

### 3.3 BGM/版权检测
```
自动检测:
  - 音乐是否在TikTok版权曲库
  - 是否涉及未授权影视片段
  - 是否含他牌LOGO露出
处理: 标记后需版权确认, 否则替换
```

### 3.4 视频风险分

```
总分 = 100分
扣分标准:
  - 封面违规: -20分
  - 医生制服: -30分（直退）
  - 对比图违规: -15分
  - 字幕含违禁词: -10分/个
  - 版权问题: -15分

结果判定:
  ≥ 80 → ✅ 上架
  < 80 → ❌ 退回修改
```

## 四、上架前全量终审（P3）

### 4.1 检查清单

```
□ 产品标题: 违禁词扫描通过
□ 产品描述: 功效宣称合规
□ 产品主图: 无医生/医疗暗示
□ 产品标签: 成分表完整/国家语言
□ 价格: 无虚假原价/价格欺诈
□ 视频: 无违规帧/字幕合规
□ 资质: 备案信息完整
□ 评论: 无刷评痕迹
□ 评分: 风险总分 ≥ 80
```

### 4.2 冻结条件
出现以下任一情况，**自动冻结不上架**：
1. 高风险违禁词 ≥ 3个
2. 医疗暗示词 ≥ 1个
3. 产品无对应国家备案信息
4. 含绝对类比较级
5. 成分表不完整（缺国家语言）

## 五、上架后自动监控（P4）

### 5.1 监控指标

| 指标 | 阈值 | 触发动作 |
|------|------|----------|
| 评论中违禁词 | ≥ 2条 | 标记审核 |
| 退货率(7天) | > 15% | 暂停广告 |
| 举报次数 | ≥ 5次 | 下架审查 |
| 差评率 | > 20% | 调查原因 |
| 发货时效 | 超时3天 | 库存预警 |

### 5.2 TikTok扣分监控

```
每天自动检查:
  - 当前扣分: 0-11 → 安全
  - 12-23 → ⚠️ 预警（限流风险）
  - 24-35 → 🔴 高危（生存风险）
  - 36+ → 🆘 紧急（封店倒计时）

报警:
  扣分 ≥ 12 → 通知🥔土豆
  扣分 ≥ 24 → 全量暂停上新
  扣分 ≥ 36 → 全量冻结（整改计划提交前）
```

## 六、急停SOP（风险爆发时）

### 6.1 一键急停
```bash
# 快速下架所有待上架商品
python3 risk_controller.py --emergency-stop --reason="[原因]"

# 暂停所有投放广告
python3 risk_controller.py --pause-ads

# 生成风险报告
python3 risk_controller.py --generate-report
```

### 6.2 分级响应

| 等级 | 触发条件 | 响应动作 | 恢复条件 |
|------|----------|----------|----------|
| L1 | 单条违规 | 退回修改+记录 | 修改通过 |
| L2 | 同品类3条违规 | 品类临时下架+排查 | 全量审核通过 |
| L3 | 违规被举报至平台 | 全店暂停+申诉准备 | 申诉通过 |
| L4 | 收到平台处罚通知 | 全量冻结+法务介入 | 整改完成+平台解封 |
