## 一、总览：3品类×5国风控等级矩阵

| 品类 | 🇹🇭泰国 | 🇲🇾马来西亚 | 🇻🇳越南 | 🇵🇭菲律宾 | 🇸🇬新加坡 |

**核心结论：**
- 🧴个人洗护（洗脸巾/沐浴球/梳子/指甲刀）和化妆工具是**风控最高优先级**——化妆品备案/标签/功效宣称规则直接适用
- 🏠家居日用品（收纳盒/降温毛巾/便携风扇/厨房收纳）**风控风险相对低**，但需关注产品安全标准（尤其是小家电类）

## 二、品类一：🎨 美妆工具（化妆刷/美妆蛋/粉扑/修眉刀/睫毛夹/化妆镜）

### 2.1 TikTok Shop美妆工具定义与风险定位

TikTok Shop将「美妆工具」归类在"Beauty & Personal Care"大类目（品类ID: 601450）下。**关键区分**：

| 子类 | 是否需化妆品备案 | 主要风险 |
|:----|:--------------:|:--------|
| 化妆刷/美妆蛋/粉扑 | ❌ 无需备案 | 材质安全（致敏） |
| 修眉刀/睫毛夹 | ❌ 无需备案 | 锐器安全/CE或等效认证 |
| 化妆镜 | ❌ 无需备案 | 无明显风险 |
| **⚠️ 如与护肤品捆绑销售（附赠/搭配）** | ✅ 需备案 | 护肤品部分触发全部化妆品规则 |

### 2.2 各国限制清单

#### 🇹🇭 泰国
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 含医疗/药物暗示的工具 | 如"祛痘刷"、"治疗刷"名称触发FDA |
| ⛔ 宣称医疗器械的工具 | 如"医用级化妆刷" |
| ⛔ 动物毛来源不明 | 泰国禁止未经检验的动物源产品进口（需FDA动物检疫） |
| ⛔ 含尖锐金属部件的可致伤工具 | 修眉刀等需符合泰国工业标准(TIS) |

#### 🇲🇾 马来西亚
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 动物毛发制品无进口许可 | 马来西亚兽医服务局(DVS)管控 |
| ⛔ 含禁售化妆品的工具套装 | 如含美白护肤品的化妆刷套装=触发化妆品类规则 |
| ⛔ 虚假宣称"Halal"的化妆工具 | 带动物毛者需Halal认证才能标注 |

#### 🇻🇳 越南
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 产品名含医疗词 | "bác sĩ makeup kit"等触发执法 |
| ⛔ 与未备案化妆品捆绑 | 套装含护肤品=需DAV备案 |
| ⛔ 直销模式未申报 | 化妆品工具跨境需商品报关+电商平台通知 |

#### 🇵🇭 菲律宾
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 未注册销售 | 需DTI Business Name注册 |
| ⛔ 材质欺诈 | 假称"natural bristle"如无证明 |
| ⛔ 虚假"FDA-approved"标注 | 化妆工具本身不需FDA备案，但不能虚假标注 |

#### 🇸🇬 新加坡
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 夸大宣称 | "clinically proven to apply better"触发虚假广告追诉 |
| ⛔ 未获C2P标签的AI内容推广 | 使用AI数字人展示化妆工具=需标注 |
| ⛔ 不安全材质 | 如含甲醛释放物等不符合HSA安全标准 |

### 2.3 认证/备案要求

| 国家 | 要求 | 详情 |
|:----|:-----|:-----|
| 🇹🇭泰 | 无强制化妆品备案 | 纯工具类不需FDA化妆品通报；但搭售护肤品时触发 |
| 🇹🇭泰 | TIS工业标准(锐器类) | 修眉刀等锐器建议符合TIS标准以便通关 |
| 🇲🇾马 | 无强制化妆品备案 | 工具类不需NPRA通知 |
| 🇲🇾马 | 进口许可证 | 含动物毛的化妆刷需DVS进口许可+健康证书 |
| 🇻🇳越 | 无强制备案 | 纯工具类不需DAV通知 |
| 🇵🇭菲 | DTI注册 | 必须注册Business Name（全套开店必备） |
| 🇸🇬新 | 无特殊要求 | 但需满足HSA一般产品安全要求 |

**实操建议**：美妆工具品类在所有5国的主要壁垒来自**宣称文案**而非备案。修眉刀需注意各国锐器管制标准（可放入产品说明中标注安全测试）。

### 2.4 知识产权风险

| 风险类型 | 风险等级 | 说明 |
|:---------|:--------:|:-----|
| 品牌商标侵权 | 🔴高 | 化妆刷常有假冒国际品牌(如Real Techniques、Sigma、MAC等)，需确认1688货源非仿品 |
| 外观设计专利 | 🟡中 | 化妆工具外观（如特殊形状化妆刷柄、化妆蛋形状）可能有各国设计专利保护 |
| 品牌名冲突 | 🔴高 | 产品Listing中不得使用"like MAC"、"dupe of Sigma"等比较标签 |
| 图片版权 | 🟢低 | 避免直接使用品牌官方图 |

**风控红线**：
- ❌ 标题/描述中不能提其他品牌名
- ❌ 不能使用"同款""similar to"等引导比较词
- ✅ 确认1688供应商已授权或为非品牌通用款
- ✅ 使用自己拍摄的产品图/视频

## 三、品类二：🧴 个人洗护（洗脸巾/沐浴球/梳子/指甲刀套装）

### 3.1 品类风险定位

个人洗护品是**风控最高品类**，原因是各国对该类产品（尤其是面部接触型产品）监管最严：

| 子类 | 需否化妆品备案 | 主要风险 |
|:----|:--------------:|:--------|
| ✅ **洗脸巾/沐浴球** | ❌（不含化学成分则免） | 材质安全/细菌标准 |
| ✅ **梳子** | ❌ | 材质安全 |
| ⚠️ **指甲刀套装** | ❌ | 锐器安全 |
| ⚠️ **如含护肤成分（如湿巾含保湿）** | ✅ 需备案 | 触发全部化妆品规则 |

### 3.2 各国限制清单

#### 🇹🇭 泰国 — 最严
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 含药妆成分的洗护工具 | 如含抗菌/除螨成分的洗脸巾=触发FDA药品管制 |
| ⛔ 宣称医疗功效 | "治疗痘痘洗脸巾""杀菌沐浴球"直接封店 |
| ⛔ 无泰文标签 | 所有产品标签必须含泰文：品名+成分(如有)+使用说明+制造商信息 |
| ⛔ 未通报的化妆品套装 | 若洗护品含肥皂/沐浴露=需化妆品通报 |
| ⛔ 宣称"instant whitening" | 洗脸巾/沐浴球白不美白都不可如此宣传 |

#### 🇲🇾 马来西亚
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 80%标签不合格风险 | 马来语标签必须包含：产品名、成分(Bahan-bahan)、使用方法、进口商信息 |
| ⛔ 虚假Halal认证 | 沐浴球/洗脸巾不可擅自标Halal（需Jakim认证） |
| ⛔ 含禁售成分 | 如抗菌成分三氯生、三氯卡班在马来西亚受限 |
| ⛔ 国标抽检重点 | 美白类/面部接触类产品为NPRA抽检重点 |
| ⛔ 虚假"dermatologist tested" | 需有检测报告 |

#### 🇻🇳 越南
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 绑定未备案护肤品销售 | 越南要求化妆品通过DAV通知 |
| ⛔ 不含越南语标签 | 所有信息需越南语（品名、使用方法、警示语） |
| ⛔ KOL未经验证推荐产品 | 2025新广告法+Kera案判刑先例 |
| ⛔ 直播未标"Quảng cáo" | 所有付费推广必须标注"此为广告" |
| ⛔ 产品信息与报关不一致 | 2025新规加强跨境商品追溯 |

#### 🇵🇭 菲律宾
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ FDA CPN缺失 | 如含护肤成分=需要产品通知证书 |
| ⛔ 虚假代言 | FDA重点打击——KOL说"亲自用过"需证明 |
| ⛔ 宗教词 | "milagro""himala"在菲属宗教敏感 |
| ⛔ DTI Trustmark缺失 | 2025.12.31前强制要求 |

#### 🇸🇬 新加坡
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 虚假功效宣称 | "hypoallergenic""dermatologist tested"需证据→否则最高S$266,500罚款 |
| ⛔ 绝对词 | "100% safe""guaranteed""best"→触发CCS审查 |
| ⛔ 含违禁成分 | 水银/类固醇/铅→刑事处罚 |
| ⛔ POFMA责任 | 社交媒体虚假声明可刑事追诉 |

### 3.3 认证/备案要求

| 国家 | 要求 | 详情 |
|:----|:-----|:-----|
| 🇹🇭泰 | ✅ 化妆品通报(Cosmetics Notification) | 如含护肤品成分的洗护品→需向泰国FDA通报 |
| 🇹🇭泰 | ✅ 泰文标签 | 强制：品名+成分+使用方法+制造商/进口商+净含量 |
| 🇲🇾马 | ✅ NPRA通知 | 化妆品类洗护品需完成NOTIFI系统通报（先通报后上架） |
| 🇲🇾马 | ✅ 马来语+英语双语标签 | 80%被查原因=标签不合规 |
| 🇻🇳越 | ✅ DAV通知 | 化妆品类需化妆品通知编号 |
| 🇻🇳越 | ✅ 越南语标签 | 强制：品名、用途、警示语全越南语 |
| 🇵🇭菲 | ✅ FDA CPN | 化妆品类需产品通知证书 |
| 🇵🇭菲 | ✅ DTI Business Name | 所有卖家必须注册 |
| 🇸🇬新 | ✅ 一般产品安全 | 需符合HSA健康产品安全标准 |
| 🇸🇬新 | ✅ AI标签+Branded Content标签 | TikTok平台规则强制 |

**关键判断标准**（纯洗护工具 vs 含护肤成分）：
```
洗脸巾（纯棉材质、无添加） → ❌ 不需备案
洗脸巾（含芦荟/茶树精油） → ✅ 需化妆品备案（触发各国化妆品定义）
沐浴球（纯尼龙/丝瓜络） → ❌ 不需备案
沐浴球（含香皂/沐浴露注入） → ✅ 需化妆品备案
梳子（纯塑料/木头） → ❌ 不需备案
指甲刀套装（纯金属） → ❌ 不需备案
```

### 3.4 知识产权风险

| 风险类型 | 风险等级 | 说明 |
|:---------|:--------:|:-----|
| 品牌商标侵权 | 🔴高 | 洗脸巾/梳子/指甲刀套装常有品牌仿冒(如无印良品风格/特定形状) |
| 外观设计专利 | 🟡中 | 特殊形状的梳子/指甲刀可能受各国外观设计保护 |
| 图案版权 | 🟡中 | 洗脸巾包装图案、梳子手柄花纹可能受版权保护 |
| 化妆品品牌侵权 | 🔴高 | 套装中如含品牌护肤品=需品牌授权 |

**风控红线**：
- ❌ 不能使用"无印同款""MUJI style"等引导比较词
- ❌ 不能Copy知名品牌的包装设计
- ✅ 洗脸巾/梳子到货后需查材质安全性
- ✅ 指甲刀套装需检查锐器安全标准

## 四、品类三：🏠 家居日用品（收纳盒/降温毛巾/便携风扇/厨房收纳）

### 4.1 品类风险定位

家居日用品是**风控最低品类**，但也分几个子类：

| 子类 | 风险 | 需注事项 |
|:----|:----:|:--------|
| ✅ **收纳盒/收纳箱** | 🟢低 | 材质安全（食品接触类才需认证） |
| ✅ **降温毛巾** | 🟡中 | 如含化学成分（冷感剂）需关注 |
| ⚠️ **便携风扇** | 🟡中 | **如含锂电池则触发电池运输/安全规则** |
| ✅ **厨房收纳架/沥水架** | 🟢低 | 食品接触类需关注 |
| ⚠️ **厨房小工具(削皮器/切菜器等)** | 🟡中 | 锐器安全/食品接触材料 |

**关键注**：临时归类下的厨房用品/小家电多以厨房小工具为主（非独立厨房电器），如涉及电动类（便携风扇等）需特别关注。

### 4.2 各国限制清单

#### 🇹🇭 泰国
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 含违禁化学品的降温毛巾 | 如含冷却化学剂未标注成分 |
| ⛔ 无TIS认证的电器 | 便携风扇如需接入电源需TIS标准 |
| ⛔ 含锂电池产品运输违规 | 锂电池空运受限 |
| ⛔ 食品接触材料无合规声明 | 厨房收纳盒接触食物需符合TIS食品接触材料标准 |

#### 🇲🇾 马来西亚
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 电器无SIRIM认证 | 便携风扇（如带USB充电）需SIRIM认证 |
| ⛔ 电池运输违规 | 含锂电池产品需符合马来西亚海关电池条例 |
| ⛔ 食品接触材料不合规 | 厨房收纳如接触食物需符合SIRIM食品接触标准 |

#### 🇻🇳 越南
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 电器无CR Mark | 便携风扇需越南强制认证(CR Mark) |
| ⛔ 食品接触材料未声明 | 需符合QCVN食品接触标准 |
| ⛔ 含违禁塑化剂 | 收纳盒如邻苯二甲酸酯超标=违规 |

#### 🇵🇭 菲律宾
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 电子产品无PS/ICC认证 | 便携风扇需产品安全(PS)或进口商品清关(ICC)认证 |
| ⛔ 虚假材质宣称 | "bamboo""natural"无证明=DTI处罚 |
| ⛔ 价格欺诈 | 虚假原价→DTI消费者投诉高发 |

#### 🇸🇬 新加坡
| 禁止项 | 说明 |
|:------|:-----|
| ⛔ 电器无Safety Mark | 便携风扇需CPS(Consumer Protection Safety)认证 |
| ⛔ 食品接触材料不合规 | 需符合Singapore Food Agency(SFA)标准 |
| ⛔ 虚假环保声明 | "eco-friendly""green"需CCS指南验证 |
| ⛔ WiFi/蓝牙产品无IMDA认证 | 如便携风扇含蓝牙功能需IMDA注册 |

### 4.3 认证/备案要求

| 国家 | 子类 | 要求 |
|:----|:-----|:-----|
| 🇹🇭泰 | 收纳盒/厨房收纳 | 无强制，食品接触类建议符合TIS标准 |
| 🇹🇭泰 | 便携风扇(无电池) | 如需插电使用需TIS认证 |
| 🇹🇭泰 | 便携风扇(含锂电池) | TIS认证+UN38.3电池报告 |
| 🇹🇭泰 | 降温毛巾(纯物理) | 无强制要求 |
| 🇲🇾马 | 收纳盒/厨房收纳 | 无强制 |
| 🇲🇾马 | 便携风扇(含电池) | SIRIM认证+电池合规 |
| 🇲🇾马 | 降温毛巾(含化学剂) | NPRA可能介定入药类管控 |
| 🇻🇳越 | 收纳盒(食品接触) | 建议QCVN标准检测 |
| 🇻🇳越 | 便携风扇 | CR Mark(强制) |
| 🇵🇭菲 | 收纳盒 | 无强制 |
| 🇵🇭菲 | 便携风扇 | PS/ICC认证 |
| 🇸🇬新 | 便携风扇(含电池/蓝牙) | Safety Mark+IMDA(含蓝牙) |
| 🇸🇬新 | 食品接触收纳 | 无强制，但建议SFA标准测试 |

### 4.4 知识产权风险

| 风险类型 | 风险等级 | 典型场景 |
|:---------|:--------:|:---------|
| 外观设计专利 | 🔴高 | 收纳盒/风扇的工业设计常受保护（尤其日本/韩国设计） |
| 品牌商标侵权 | 🟡中 | 较少——家居品类品牌化程度低 |
| 图案/美术版权 | 🟡中 | 包装上的卡通/图案可能受版权保护 |
| 功能性专利 | 🟢低 | 除非是高技术含量产品 |

## 五、5国风控基线交叉分析

### 5.1 禁售/限制通用规则（所有品类适用）

| 规则 | 适用国家 | 处罚 |
|:----|:--------:|:----|
| ❌ 销售禁售品类 | ALL | 立即下架+扣分(AHR) |
| ❌ 导流到站外 | ALL | 限流+扣分 |
| ❌ 刷单/虚假订单 | ALL | 90%封号原因之一 |

## 七、选品阶段风控检查清单

### 选品导入必查 6 项

```
□ ① 品类界定 → 本产品属于哪一类？（美妆工具/个人洗护/家居日用品）
□ ② 备案判断 → 是否含护肤/化妆品成分？→ 是则查各国备案要求
□ ③ 材质安全 → 是否含动物毛/化学品/锂电池/锐器？→ 是则查各国安全认证
□ ④ 食品接触 → 是否接触食物？→ 是则查食品接触标准
□ ⑤ 品牌检查 → 是否可能侵犯他国商标/设计专利/版权？
□ ⑥ 宣称红线 → 标题/描述是否含任何医疗效暗示或绝对比较词？
```

### 选品阶段风险分卡

```
按项计分：
  每项"是" = +1风险分

风险分级：
  0-1分 → 🟢 安全（可直接进入文案阶段）
  2-3分 → 🟡 预警（需要补充材料/修改描述）
  4分+  → 🔴 高风险（需土豆+苦瓜联合评估）

例：
  修眉刀 → 品类界定✓(1) + 锐器✓(1) = 2分 → 🟡预警
  洗脸巾带"抗菌"宣称 → 品类界定✓(1) + 功效宣称✓(1) = 2分 → 🟡预警
  沐浴球含芦荟精华 → 品类界定(洗护)✓(1) + 含护肤成分✓(1) + 需备案✓(1) = 3分 → 🟡预警
  USB风扇含锂电池 → 品类(家居)✓(1) + 锂电池✓(1) + 需各国电气认证✓(1) + 电池运输✓(1) = 4分 → 🔴高风险
```
