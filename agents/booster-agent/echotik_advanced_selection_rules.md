## 📌 交付物1: 5条选品判断黄金规则（可复用Prompt）

### 规则1：GPM+销量涨幅双重验证 → 确定性机会判断

```
判断逻辑：
  高GPM（≥80，泰国≥100） × 高销量涨幅（7D≥30%）= 确定性机会
  补充验证：查看7天销量绝对值 ≥ 50件（排除偶然暴涨）

置信度分层：
  🔥 确定性机会：GPM≥100 + 涨幅≥50% + 7D销量≥200
  ⚡ 高潜机会：GPM≥80 + 涨幅≥30% + 7D销量≥100
  👀 观察机会：GPM≥60 + 涨幅≥30% + 7D销量≥50（需二次验证）
  ❌ 排除：GPM<60 或 涨幅<30% 或 7D销量<50（跟风陷阱）

⚠️ 注意：GPM高但涨幅小=老爆款，竞争已饱和；涨幅高但GPM低=内容驱动非产品力
```

### 规则2：竞争度三维评估 → 蓝海/红海判定

```
评估维度：
  1️⃣ 带货达人数 (total_ifl_cnt)
     - ≤50：蓝海（抢滩窗口）
     - 50~300：中度竞争（需差异化内容）
     - >300或>500：红海（谨慎进入，除非供应链碾压）

  2️⃣ 关联视频数 (total_video_cnt)
     - ≤30：内容蓝海
     - 30~150：中等
     - >150：内容竞争激烈

  3️⃣ 近7天视频增量 (total_ifl_video_7d_cnt)
     - 增量大+总量小=爆发前夜（最佳切入点）
     - 增量小+总量大=已过黄金期
     - 增量小+总量小=不活跃品类（需确认需求）

蓝海判定标准（同时满足3条）：
  □ total_ifl_cnt ≤ 50
  □ total_video_cnt ≤ 30
  □ 7D销量 ≥ 100（证明有需求但供给不足）
```

```

  判断维度：
  1️⃣ 带货达人数 (total_ifl_cnt)：越多说明达人认可度高
  2️⃣ 达人带货效率 (per_product_ifl_sale_cnt)：
     - 达人单推该品销量 > 100件 = 品好推
     - 达人单推该品销量 < 10件 = 品难卖
  3️⃣ 达人类型：
     - 中小达人（1-10万粉）推 = 更真实、更可信
     - 大达人推 + 视频转化高 = 供应链问题（难复制）

  达人筛选参数建议（用于 influencer/list 接口）：
    达人分类：Beauty / Life Style / Shopping & Retail
    带货标识：sales_flag=1（视频带货）或3（直播+视频）
    min_total_followers=10000（至少万粉验证）
    influencer_sort_field=4（平均播放量排序）
    达人带货效率高的品 = 天然的选品质量验证

  视频关联判断（使用 product/video/list API）：
    - 查看视频desc和话题标签 → 复制爆款标题/关键词
    - 视频总销量/播放量比 > 1% = 转化率高
    - 点赞率（点赞/播放）> 3% = 内容有吸引力
    - 分享率（分享/播放）> 0.5% = 有传播力
```

```
最终排序权重调整方案：
  score = (GPM/100 × 0.25) + 
          (涨幅%/100 × 0.25) + 
          (蓝海度 × 0.20) +       # total_ifl_cnt越低分越高
          (价格带匹配度 × 0.15) +   # 越贴近最优转化价带分越高
          (达人验证度 × 0.15)       # 带货达人数越多分越高

  蓝海度 = max(0, 1 - total_ifl_cnt/200)  # 0-1之间的值
  价格带匹配度 = 1 if spu_avg_price在最优价带 else 0.5
```
