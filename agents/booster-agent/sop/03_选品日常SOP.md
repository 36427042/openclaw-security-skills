# 🍅 选品日常SOP — 可执行操作流程

> 版本：v1.0 | 2026-05-11 天赐确认
> 核心原则：**30分钟跑一圈，不纠结，数据说话**

---

## ⏰ 每天早上跑选品的固定步骤

### Step 1：拉各品类TOP 100（3-5分钟）

**操作：**
```
python3 scripts/booster_selection.py --categories 美妆工具,家居<500g,日用品 --countries TH,MY,VN,PH,SG --limit 100
```

**判断标准：**
- 美妆工具 → EchoTik `product/list` → `category_id=601537`
- 家居<500g → EchoTik `product/list` → `category_id=600001`
- 日用品 → EchoTik `product/list` → 美妆护肤大类下筛选

**⚠️ 注意点：**
- 如果API 500 → 停1.5秒重试，最多3次
- 触发限流 -> 切换国家，轮流拉
- 每日12:00 cron自动触发

---

### Step 2：筛涨幅 ≥ 30%（2-3分钟）

**标准：**
- 近7天销量涨幅 ≥ 30%（EchoTik `sales_trend_flag=1`）
- 排除：涨幅>300%但views=0（刷单嫌疑）
- 排除：涨幅>200%但7天销量<50（脉冲品不可持续）

**筛选命令：**
```
# 原始数据过滤
python3 -c "
import json
data = json.load(open('booster_selection_raw.json'))
filtered = [d for d in data if d.get('daily_growth', 0) >= 30 and d.get('7d_sales', 0) >= 50]
print(f'通过涨幅筛选: {len(filtered)}/{len(data)}')
json.dump(filtered, open('booster_step2.json', 'w'), ensure_ascii=False)
"
```

**判断逻辑：**
| 涨幅区间 | 标签 | 动作 |
|---------|:----:|------|
| ≥ 100% | 🔥 暴涨 | 核查是否脉冲（回头Step 5验证） |
| 50%~100% | ⭐ 高增长 | 进入下一轮 |
| 30%~49% | ✅ 增长 | 进入下一轮 |
| < 30% | ❌ 平缓 | 直接淘汰 |

---

### Step 3：筛 GPM ≥ 80 （泰国≥100）（2-3分钟）

**GPM代理计算公式：**
```
GPM代理 = (售价 × 佣金率%) × 30
（排除views=0导致的极端值）
```

**处理规则：**
- GPM ≥ 150 → 🏆 满分品（直接推荐）
- GPM 100~149 → ⭐ 优质品（进入综合评分）
- GPM 80~99（泰国100+） → ✅ 基础合格
- GPM < 80（泰国<100） → ❌ 直接淘汰
- GPM < 60 → 即使涨幅高也含内容驱动水分，排除

**筛选命令参考：**
```
python3 -c "
import json
data = json.load(open('booster_step2.json'))
th_threshold = 100
filtered = [d for d in data if (d.get('gpm', 0) >= (th_threshold if d.get('country')=='TH' else 80))]
print(f'通过GPM筛选: {len(filtered)}/{len(data)}')
json.dump(filtered, open('booster_step3.json', 'w'))
"
```

### Step 4：筛竞争度 + 差评率（5分钟）

**同时检查4项：**

```
□ 评价数 100~3000？                    → 改在100-3000之间
□ 差评率 ≤ 3%？                         → 差评数/总评价 ≤ 0.03
□ 上架 ≤ 60天？                         → 新品红利窗口
□ 竞争度（带货达人数 total_ifl_cnt）：→ ≤ 100 通过，100~300验证，>300淘汰
```

**竞争度三维联动判断：**

| 维度 | 蓝海（✅） | 中度（⚠️） | 红海（❌） |
|:----:|:--------:|:---------:|:--------:|
| 带货达人数(ifl) | ≤ 50 | 50~300 | > 300 |
| 关联视频数(video_cnt) | ≤ 30 | 30~150 | > 150 |
| 7天视频增量 | 增量大+总量小 | 中等 | 增量小+总量大 |

**蓝海三条件（同时满足才算蓝海）：**
1. `total_ifl_cnt ≤ 50`
2. `total_video_cnt ≤ 30`
3. `近7天销量 ≥ 100`（有需求但供给不足）

**筛选命令：**
```
python3 -c "
import json
data = json.load(open('booster_step3.json'))
filtered = []
for d in data:
    reivew_count = d.get('review_count', 0)
    bad_rate = d.get('bad_review_rate', 0)
    ifl = d.get('total_ifl_cnt', 999)
    days_on = d.get('days_on_shelf', 999)
    if 100 <= reivew_count <= 3000 and bad_rate <= 0.03 and ifl <= 100 and days_on <= 60:
        filtered.append(d)
print(f'通过竞争度+差评率筛选: {len(filtered)}/{len(data)}')
json.dump(filtered, open('booster_step4.json', 'w'))
"
```

### Step 5：交叉验证 — 真实性鉴别（3-5分钟）

**跟风卖家 vs 真实爆款鉴别矩阵：**

| 特征 | 🚩 跟风卖家（淘汰） | ✅ 真实爆款（保留） |
|:---:|:------------------:|:----------------:|
| 达人类型 | 少量大达人集中推 | 多类型达人分散推 |
| 达人数 | < 10个 | 20+达人 |
| 视频内容 | 相似度高（搬运） | 多样化（UGC原创） |
| 销售曲线 | 单日脉冲式上涨 | 持续稳步增长 |
| 视频/达人数比 | 视频/达人数 > 50 | < 20（达人产出效率高） |

**真实性分数公式：**
```
authenticity_score = total_video_cnt / total_ifl_cnt

< 20:   ✅ 优质（达人产出效率高，品好推）
20~50:  ✅ 正常（达人有效产生内容）
> 50:   ⚠️ 可疑（很多视频来自很少达人，需进一步排查）
```

**快速判定（没有视频/达人明细时使用近似）：**
```
可疑红色信号：
  1. 价格突然打五折（大概率清货或刷单）
  2. 日涨幅 > 200% + 达人数 < 5（刷量特征明显）
  3. 7天销量是30天销量的50%以上（30天数据短，不可信）
  4. 差评率 0%（太完美，异常）
```

### Step 6：综合评分排序 TOP 20（5分钟）

**使用交叉乘积评分法 v2.2：**

```python
# 核心公式
gpm_score = min(1.0, GPM / 150)
growth_score = min(1.0, 涨幅% / 50)
blue_ocean_score = max(0, 1 - total_ifl_cnt / 200)
price_fit_score = 1.0 if 在最优转化价带 else 0.6 if 附近价带 else 0.2

base_score = (gpm_score ** 1.2) * (growth_score ** 0.8) * (blue_ocean_score ** 0.6) * (price_fit_score ** 0.4)

country_weight = {
    'TH': 1.0, 'MY': 0.95, 'VN': 0.85, 'PH': 0.80, 'SG': 0.65
}
final_score = base_score * country_weight[country]
```

**评级 & 行动：**

| 分数区间 | 评级 | 当天动作 |
|:--------:|:----:|---------|
| ≥ 0.50 | 🔥 S级 | 马上推给土豆，当天上架 |
| 0.35~0.49 | ⭐ A级 | 纳入备选池，2天上架 |
| 0.20~0.34 | 👀 B级 | 二次验证，3天内决定 |
| < 0.20 | ❌ C级 | 暂缓，不入选品池 |

**5国各品类每天保留：**
- S级 每个品类×国家产出0-2个 → 非每日必有
- A级 每个品类×国家产出2-5个 → 主选品池
- B级 按需保留 → 观察池
- 全品类×5国日均产出：S 5-10个 / A 20-30个

## 📋 每日自查清单

**基础8条（必须全过）：**
```
□ 近7天涨幅 ≥ 30%（核实7天vs30天数据）
□ GPM ≥ 80（泰国≥100）
□ 评价数 100~3000？
□ 差评率 ≤ 3%？
□ 上架 ≤ 60天？
□ 产品展示性强（视觉冲击力）
□ 价格在合理区间（见各国价格带）
□ 重量 < 500g（家居用品强制）
```

**高级3条（能过就过，不过则在报告中注明原因）：**
```
□ 竞争度：带货达人数 ≤ 100？
□ 视频验证：至少1条带货视频有销量？
□ 达人验证：至少2个达人带货该品？
```

**排除项（只要触发1条就淘汰）：**
```
□ ❌ 品牌产品 → 侵权风险
□ ❌ 液体/超敏感 → 运输风险高
□ ❌ 易碎品 → 退货率高
□ ❌ 需要资质/强管控 → FDA等
□ ❌ 销量过万 → 竞争太卷
□ ❌ 沾药/功效宣称 → 封店风险
□ ❌ 单店同品超过3款 → 内卷
□ ❌ ifl达人数 > 500 → 红海
□ ❌ GPM < 60 → 内容驱动非产品力
```

## 📎 紧急情况处理

### API挂了怎么办？
```
EchoTik API 500:
  1. 停30秒重试1次
  2. 如果连5次都500：切到Sorftime/Shopee手查
  3. 手查替代方案：Shopee各国站搜索TOP+查看评价+反推数据
  4. 当天输出改为：手查报告（质量>数量）
```

### 当天0个通过筛选怎么办？
```
0合格品 → 不强行凑数
  1. 检查筛选条件（是否过严）
  2. 暂时放宽到GPM≥60搜索
  3. 如果还是0 → 当天出"市场动态报告"（什么在涨/什么在跌）
  4. 空窗期说明：当前是选品周期低谷，反而要先占坑
```

### 发现强势新品类怎么办？
```
新品类发现 → 不动 → 先备案
  1. 记入report的"特殊发现"栏
  2. 连续3天出现 → 正式提议拓品
  3. 土豆确认后才加入选品管线
```
