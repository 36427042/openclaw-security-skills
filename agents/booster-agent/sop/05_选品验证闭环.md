# 🍅 选品验证闭环 — 从选品到上架再到7天数据验证

> 版本：v1.0 | 2026-05-11
> 核心原则：**选品不是终点，卖出去才是。数据不会骗人，7天见分晓。**

## ✅ 验证闭环的5个判断节点

### 节点0：上架前（D0）— 基线记录

上架前必须记录以下基线数据：

```
□ 商品售价
□ 1688采购成本
□ 期望利润率
□ 上架数量（默认50件试水/100件正常）
□ 主图准备（3-5张）
□ 达人关联视频（如果已有）
□ 竞品价格区间
```

**只有完成基线的品才能上架。**

---

### 节点1：上架后24小时（D1）— 冷启动检查

**检查指标：**

| 指标 | 成功标准 | 失败标准 | 动作 |
|:----|:--------:|:--------:|------|
| 商品浏览(impression) | ≥ 50次 | < 10次 | 检查标题/主图/关键词 |
| 商品点击率(CTR) | ≥ 3% | < 1% | 换主图/测封面 |
| 达人领取样品数 | ≥ 1个 | 0个 | 推给达人池主动邀约 |
| 库存消耗 | ≥ 5件 | 0件 | 检查定价/竞争 |

**判定：**
```
✅ 如果impression ≥ 50 + CTR ≥ 3% → 冷启动成功，继续
⚠️ 如果impression ≥ 50 + CTR < 3% → 换主图再观察12小时
❌ 如果impression < 50 + 任何达人未领样 → 标"冷启失败"，检查标题/关键词
```

---

### 节点2：上架后3天（D3）— 中场检查

**检查指标：**

| 指标 | 成功标准 | 观察标准 | 失败标准 |
|:----|:--------:|:--------:|:--------:|
| 7天销量(累计) | ≥ 30件 | 10-29件 | < 10件 |
| 达人带货数 | ≥ 3个达人 | 1-2个 | 0个 |
| 达人视频数 | ≥ 3条视频 | 1-2条 | 0条 |
| 差评率 | ≤ 3% 且≥1个评价 | 1-3%或0评价 | > 3% |
| 自然搜索排名 | TOP 100有出现 | >100位 | 无排名 |

**判定规则：**

```
✅ 达标 ≥ 3项成功标准 → 进入"全力推进"状态
  追加动作：
    - 增加采购单（从50→500件）
    - 玉米出3-5条差异化视频
    - 生菜出3组不同角度文案
    - 推给更多达人（发送样品）

⚠️ 处于灰色区 → 进入"针对性优化"
  案例诊断：
    a) 浏览高+转化低 → 优化详情页（主图/视频/评价）
    b) 达人推但不出单 → 检查定价/佣金比例
    c) 零达人领样 → 提佣金（从10%→15%）/降价
  观察时限：再等2天（D5二次检查）

❌ 失败 ≥ 3项失败标准 → 立即"标记暂缓"
  动作：
    - 暂停推广（不再投流量）
    - 剩余库存怎么办？（见下文）
    - 记入GEP失败模式
```

---

### 节点3：上架后7天（D7）— 最终裁决

**最终判断指标表（核心决策矩阵）：**

| # | 指标 | 成功(S级继续) | 待观察(A级再等) | 失败(淘汰) |
|:-:|:----|:------------:|:--------------:|:---------:|
| 1 | **7天总销量** | ≥ 100件 | 30-99件 | < 30件 |
| 2 | **7天GMV** | ≥ $500 | $100-499 | < $100 |
| 3 | **GPM（平台数据）** | ≥ $80 | $40-79 | < $40 |
| 4 | **达人视频数** | ≥ 5条 | 2-4条 | 0-1条 |
| 5 | **达人带货达人数** | ≥ 3人 | 1-2人 | 0人 |
| 6 | **差评率** | ≤ 3% | 3-5% | > 5% |
| 7 | **视频转化出处率** | ≥ 3%（视频看→购买） | 1-3% | < 1% |
| 8 | **退货率** | ≤ 5% | 5-10% | > 10% |

**综合判定规则：**

```
🔥 全明星品：成功8项中达标≥6项
  → 100%确认，加单1000件+
  → 安排达人大批量推
  → 提升预算到正常投放水平

⭐ 潜力品：成功8项中达标4-5项 + 无淘汰项
  → 确认维持，加单至500件
  → 继续观察（D14再检）
  → 优化内容方向

👀 观察品：无淘汰项但成功项≤3
  → 维持原状
  → 不追加投入
  → 每周再检一次（D14/D21最多到D30）

❌ 淘汰品：淘汰项≥2项
  → 立即停止投入
  → 转入淘汰处理流程
```

## 📉 淘汰品处理流程

### 清仓策略

| 情况 | 策略 | 时间窗口 |
|:----|------|:--------:|
| 库存≤50件 | 降价20%出清，不再采购 | 3天 |
| 库存50-200件 | 降价30%出清 + 达人限时出清佣金 | 7天 |
| 库存200-500件 | 降价50%回流 + 打包促销（强跟弱品一键出） | 14天 |
| 库存>500件 | 出给Shopee站、1688供应链、二手渠道 | 30天 |

### 失败原因分类（录入GEP引擎）

```
失败代码对照表：

E-01: 定价错误（过高/过低 → 价格带不对）
E-02: 竞争过激（上架后发现达人暴增 → 进入红海）
E-03: 品不合适（视觉吸引力不够 → 内容展示差）
E-04: 达人推不动（佣金太低 → 需要15%+才可能推）
E-05: 需求不足（品类认知不够 → 没有人搜）
E-06: 供应链问题（断货/质量差 → 差评突升）
E-07: 季节/趋势错误（选错时间窗口 → 品到了但旺季已过）
E-08: 侵权/违规（被下架/被封店 → 踩坑）
```

**每次淘汰都记录失败代码，累积到GEP引擎。**
**核心进化：同样的失败代码，同一品类下不允许出现2次。**

## 📝 运维操作文档

### 日常执行清单

```
每天早上（在跑完选品SOP后）：
  [ ] 查看昨天上架的品，记录D1检查数据
  [ ] 3天前上架的品，做D3中场检查
  [ ] 7天前上架的品，做D7最终裁决

每周一：
  [ ] 更新选品健康度仪表盘
  [ ] 汇总上周淘汰品的失败代码
  [ ] 输出上周D7通过率（目标≥40%）
  [ ] 如果通过率 < 30% → 复盘选品条件是否需要放宽/收紧

每月初：
  [ ] 汇总上月选品全链路数据
  [ ] 统计各品类×国家的"通过率排行"
  [ ] 判断品类/国家的选品策略是否需要调整
  [ ] 更新GEP引擎的历史教训库
```
