## 四、排除项（必勾）

- ❌ **品牌产品** — 避免侵权/投诉
- ❌ **液体** — 超敏感/运输风险高
- ❌ **易碎品** — 退货率高
- ❌ **玻璃制品** — 🔴 天赐2026-05-15追加：绝对不要玻璃制品，易碎退货率极高
- ❌ **需要资质强管控品** — 如FDA认证/化妆品备案
- ❌ **销量过万的超级爆款** — 竞争太卷，不做标品
- ❌ **强管控美妆**（沾药/功效宣称类）— 封店风险
- ❌ **单店同品超过3款** — 避免店铺内卷
- ❌ **同样产品只选1种** — 🔴 天赐2026-05-15追加：同一细分品类只选1个SKU，不重复
- ❌ **total_ifl_cnt > 500** — 红海品类，达人竞争太激烈
- ❌ **GPM < 60** — 即使涨幅高也是内容驱动非产品力

## 🆕 天赐2026-05-15 选品4条新规（追加）

1. **同样产品只选1种** — 同一品类不要重复选，精选最优1款
2. **不要易碎玻璃制品** — 绝对禁止玻璃材质产品，运输风险不可控
3. **不只看销量，多看增长潜力** — 爆品可能价格内卷严重，优先找：
   - 近期增幅≥50%的新品
   - 评价≥4.5分且复购率高的品
   - 有成为爆款潜力的新品（非已经爆的）
4. **新品爆发潜力优先于存量爆品** — 核心逻辑：找上升期新品，不是顶峰期爆品

## 五、排序方式 — 综合评分公式

### v2.2 交叉乘积法（Cross Product Score）

基于交叉分析发现：单维度高分不能代表整体，用乘积效应放大风险/机会信号。

```python
# 核心公式：BASE_SCORE = gpm^1.2 × growth^0.8 × blue^0.6 × price^0.4

# 各子分数归一化（0-1）：
gpm_score = min(1.0, GPM / 150)         # GPM 150=满分
    # 指数1.2：对高GPM非线性奖励
    
growth_score = min(1.0, 涨幅% / 50)   # 50%涨幅=满分
    # 指数0.8：温和放大增长影响

blue_ocean_score = max(0, 1 - total_ifl_cnt / 200)  # 达人数200=归零
    # 指数0.6：蓝海度适度影响，避免过优

price_fit_score = (
    1.0 if 在最优转化价带 else
    0.6 if 在附近价带 else
    0.2  # 远离最优价带
)
    # 指数0.4：价格匹配度温和影响

BASE_SCORE = (
    (gpm_score ** 1.2) *
    (growth_score ** 0.8) *
    (blue_ocean_score ** 0.6) *
    (price_fit_score ** 0.4)
)

# 国别加权（基于市场策略优先级）
country_weight = {
    'TH': 1.0,   # 最大市场（$3B Q1）+ ATV$9最高
    'MY': 0.95,  # 高倍率市场（×6.2-6.8）
    'VN': 0.85,  # 增长市场，价格敏感
    'PH': 0.80,  # 低价冲量市场
    'SG': 0.65,  # 小市场
}

FINAL_SCORE = BASE_SCORE * country_weight[region]
```

**综合评级标签（v2.2 阈值下调，因为乘积法分值天然低）：**
| 分数区间 | 评级 | 行动 |
|:--------:|:----:|------|
| ≥ 0.50 | 🔥 S级 | 高确定性，立即行动 |
| 0.35~0.49 | ⭐ A级 | 高潜力，可纳入备选 |
| 0.20~0.34 | 👀 B级 | 有条件，需二次验证 |
| < 0.20 | ❌ C级 | 暂缓 |
