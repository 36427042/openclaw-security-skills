| 质量评分<4.0 | 立即淘汰 |

| 涨价未提前通知 | 警告→淘汰 |
| 假货/劣质 | 立即淘汰 + 平台投诉 |

### 淘汰流程

```
1. 苦瓜安豆发现异常 → 汇报土豆

3. 累计 3 次异常 → 降级/淘汰

```
