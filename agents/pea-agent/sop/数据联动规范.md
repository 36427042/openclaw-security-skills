# 🔗 数据联动规范 v1.0 — 全伙伴数据接口标准

> **创建**: 🫘豌豆 | **日期**: 2026-05-11
> **用途**: 各伙伴（番茄/玉米/生菜/萝卜/苦瓜）按统一格式输出数据 → 🫘豌豆看板自动聚合

---

## 设计原则

1. **去中心化输入** — 各伙伴自行维护自己的数据输出文件
2. **集中化聚合** — 🫘豌豆每日跑一次聚合脚本，拉取所有伙伴数据
3. **增量追加** — 每条数据记录独立，不覆盖历史
4. **最低成本** — 每条记录仅需5-10个字段，不增加工作量

---

## 一、数据文件规范

### 文件命名

```
{伙伴标识}_data_{YYYY-MM-DD}.json
```

示例：
- `tomato_data_2026-05-11.json` — 番茄选品数据
- `corn_data_2026-05-11.json` — 玉米视频数据
- `lettuce_data_2026-05-11.json` — 生菜文案数据
- `radish_data_2026-05-11.json` — 萝卜配音/补货数据
- `bitter_data_2026-05-11.json` — 苦瓜风控数据

### 存放位置

```
/Users/a1234/.openclaw/workspace/data/partner_data/
├── tomato_data_2026-05-11.json
├── corn_data_2026-05-11.json
├── ... 
└── agg_daily_report_2026-05-11.json  (🫘聚合产出)
```

## 三、🫘豌豆聚合流程

### 聚合脚本逻辑

🫘豌豆每日跑 `aggregate_partner_data.py`：

```
1. 扫描 data/partner_data/ 下所有 *YYYY-MM-DD*.json
2. 识别 5个伙伴的数据文件
3. 按 sku_id 关联不同伙伴的数据
4. 输出聚合数据 + 触发异常检测
5. 写入 agg_daily_report_YYYY-MM-DD.json
```

### 🫘聚合脚本计划

```python
# operate_partner_aggregator.py (由🫘执行)

def aggregate_all():
    partner_files = scan_partner_data()  # 扫描目录
    sku_index = build_sku_index(partner_files)  # 按sku_id聚合
    detect_gaps(sku_index)  # 全链路断点检测
    compute_health(sku_index)  # 健康度计算
    output_aggregated_data()  # 输出聚合结果
    generate_daily_report()  # 调用日报生成器
```
