## 一、核心筛选原则

```
三必须：

❌ 不要膏霜/精华/水乳/面膜
```

## 三、产品质量标准

### （一）美妆工具通用标准

| 指标 | 要求 | 检测方法 |
|------|------|----------|
| 材质安全 | ✅ 食品级/医用级 | 质检报告 |

#### 4. 化妆工具类（睫毛夹/刮痧板等）

## 九、供应商管理流程

### （一）开发流程

```
1. 1688 搜索关键词 → 筛选 10 家候选
2. 发送首次接触话术 → 等待回复
3. 回收资质文件 → 初步评估
4. 索取样品 → 质量检验
5. 评分评级 → 确定合作等级
6. 签订合同 → 开始合作
```

### （二）日常管理

```
每日：
- 监控发货时效
- 处理售后问题

每周：
- 供应商评分更新
- 淘汰 C 级供应商

每月：
- 供应商复盘会议
- 优化供应商结构
```

### （三）备选方案

```
每个 SKU 至少储备 3 家供应商：
- 主力供应商（S 级）- 价格最优
- 备选供应商 A（A 级）- 质量最好
- 备选供应商 B（A 级）- 发货最快

断货应急：
- 主力断货→切换备选 A
- 备选 A 断货→切换备选 B
- 全部断货→下架/换品
```
