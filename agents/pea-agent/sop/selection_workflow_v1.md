## 6步工作流

### Step 1: EchoTik 市场扫品
- 用 EchoTik API 查目标品类在5国的热销品
- 看：月销量、趋势、均价、竞争度
- 输出：`~/Desktop/豌豆/候选品清单_{品类}_{date}.md`

### Step 2: 1688 找供应商 + 查运费
- 对候选品，去1688找供应商
- **通过妙手采集1688商品**
- **关键：查运费**
  - 进入妙手后台 → 已采集的1688商品详情
  - 看"尝试下单"界面或商品页的运费信息
  - 记录对应供应商的国内运费（CNY）
  - 不同供应商运费不同，必须核实
- 输出拿货价 + 运费（写入 PRODUCTS 格式）

### Step 3: 定价 + TK 比价过滤
使用定价公式 v3.0：

```
售价 = (拿货价 + 运费) ÷ 国家分母
```

| 国家 | 分母 | 货币 |
|:---:|:---:|:---:|
| TH | 0.40 | THB |
| MY | 0.37 | MYR |
| VN | 0.34 | VND |
| SG | 0.43 | SGD |

**筛选：**
- 公式价 ≤ TK同类价 × 0.92 → 通过 ✅
- 公式价 > TK同类价 × 0.92 → 淘汰 ⛔
- TK同类价来源：EchoTik API 同类商品均价

参考：`~/Desktop/TK定价公式_5国_v3.0.md`

### Step 4: 调用生菜 → 写商品详情
将合格商品列表传给生菜：
- 产品名、卖点、1688原标题
- 目标5国站点（TH/MY/VN/SG/PH）
- 每个商品需要：各站标题 + 商品描述

生菜写好后退回文案给豌豆。

### Step 4.5: 🥒 违禁词审核（新增 · 2026-05-14 天赐确认）

**生菜文案产出后 → 过苦瓜审核 → 通过的才进妙手**

审核方式（二选一）：
1. **调用苦瓜审核脚本**（推荐）：
   ```bash
   python3 ~/.openclaw/workspace/agents/bittergourd-agent/scripts/risk_controller.py \
     --action review_text \
     --text-file 生菜文案.json \
     --country TH,MY,VN,SG
   ```
2. **手动检查**：参考苦瓜违禁词库 `bittergourd-agent/sop/违禁词库_v2.0.md`（510词/5国）

审核通过标准：
- 所有站违禁词命中数为0  ✅
- 有违禁词 → 退给生菜修改 → 重新审核
- **妙手发布时平台会自动再次检测违禁内容**（save_move_collect_task），本地审核只是提前拦截

### Step 5: 写入 PRODUCTS + 调用 auto_publish.py
1. 将生菜审核通过的文案写回妙手商品详情
2. 将商品信息写入 `PRODUCTS` 字典格式
3. 调用 `python3 scripts/auto_publish.py`

### Step 6: 验证 + 汇报
- 检查各站是否上架成功
- 输出上架报告

## 输出格式要求

向 auto_publish.py 的 PRODUCTS 字典添加商品时的格式：

```python
common_id: ('产品名称', '品类', 运费_CNY, ['cid']),
# 例：
3572629730: ('不锈钢密封罐', '厨房', 10.0, '600029'),
```
