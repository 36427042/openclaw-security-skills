# 🍅 选品评分卡 — 数据驱动的选品决策工具

> **版本**: v1.0 | **维护**: 🫘豌豆
> **用途**: 番茄选出潜在SKU后，输入5维度数据 → 模型自动计算 → 输出选品建议

---

## 工作流程

```
🍅番茄选品
    │
    ├── EchoTik抓取品类数据
    ├── 1688查拿货价
    └── 填写选品评分卡输入
         │
         ▼
🫘豌豆模型计算
    ├── 市场热度、竞争生态、品类基础
    ├── 利润空间、内容适配度
    └── → P(success) + 建议动作
         │
         ▼
🥔土豆审核 → 决定上架/测试/跳过
```

## 二、评分卡计算逻辑

### 5维度加权

| 维度 | 权重 | 核心问法 |
|:----|:----:|:---------|
| 市场热度 | 25% | 这个市场现在旺不旺？ |
| 竞争生态 | 20% | 进去之后有没有肉吃？ |
| 品类基础 | 15% | 这个品类本身好不好？ |
| 利润空间 | 20% | 赚到钱了吗？ |
| 内容适配 | 20% | 视频能拍出效果吗？ |

## 三、输出解读

### 总分 → 建议动作

| 总分 | 等级 | 建议动作 |
|:---:|:----:|:---------|
| **≥85** | 🟢 高概率 | **直接上架**，批量+广告推 |
| **70-84** | 🟢 较大概率 | **正常上架**，7天观察后决策 |
| **55-69** | 🟡 中等概率 | **小规模测试**，3天内快速验证 |
| **40-54** | 🟡 低概率 | **仅作补品/平替**，注意止损 |
| **<40** | 🔴 极小概率 | **跳过**，换选其他 |

### 预计7天出单量

```
7天出单 = 总分 × 上架SKU数 × 0.12 × 投放系数

上架SKU数: 一般5-20个变体
投放系数: 不投=0.5, 普通=1.0, 重点=1.5, 大推=2.0
```

**示例：**
- 3D美妆蛋, 总分82分, 上架10SKU, 普通投放
- → 82 × 10 × 0.12 × 1.0 = **98单/7天** ✅

## 四、快速评分表（纯手工版）

如果不想跑Python，可以手算：

```
评分 = 市场热度_X + 竞争生态_X + 品类基础_X + 利润空间_X + 内容适配_X

各维度满分：
市场热度: 25分
竞争生态: 20分
品类基础: 15分
利润空间: 20分
内容适配: 20分
            ─────
总分:       100分
```

### 快速判断原则（不用算那么细）

| 情况 | 直接跳过 🔴 |
|:----|:-----------|
| GPM < 50 | 别选，市场太冷 |
| 同类竞品 > 500个 | 红海，别进 |
| 毛利率 < 30% | 赚不到钱 |
| 退款率 > 10% | 品控问题大 |
| 视频难展示 | 内容成本太高 |

| 情况 | 闭眼入 🟢 |
|:----|:---------|
| GPM > 120且涨幅>+10% | 火热赛道 |
| 同类<50且GPM>80 | 蓝海机会 |
| 毛利率>60% | 利润空间大 |
| 视频展示效果惊艳 | 内容红利 |

## 五、回测追踪

每批选品上架后，复盘数据反哺模型：

| 选品 | 预测分 | 实际7天出单 | 准确? | 校准方向 |
|:----|:-----:|:----------:|:-----:|:--------|
| 3D美妆蛋 | 82 | 待数据 | - | - |
| 便携睫毛夹 | 71 | 待数据 | - | - |
| 多功能收纳盒 | 55 | 待数据 | - | - |

> **回测周期**: 每3-5批数据复盘一次，校准维度权重
> **GEP记录**: 每次回测结果记录到GEP引擎进化
