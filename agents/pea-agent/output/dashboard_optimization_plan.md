## 二、新增：「① 总经理驾驶舱」— 一页全览

这是本次升级的核心——**一张「一眼能读出公司健康度」的主屏**。

### 字段设计（15字段，每行=1天）

```
┌─────────────────────────────────────┐
│  🌐 总经理驾驶舱 · 日报            │
├─────────────────────────────────────┤
│ 日期 │ 国家 │ 出单店铺 │            │── 基本信息
├─────────────────────────────────────┤
│ GMV │ 订单数 │ 客单价 │ AOV       │── 核心GMV指标
├─────────────────────────────────────┤
│ 退款率 │ 退款金额 │ 净GMV         │── 退款/净收入
├─────────────────────────────────────┤
│ 广告花费 │ ROAS │ GPM │           │── 投放效率
├─────────────────────────────────────┤
│ 总单品数 │ 热销TOP1 │ 出单率      │── 选品效能
├─────────────────────────────────────┤
│ 单品配送周期(天) │ 缺货预警       │── 供应链健康度
├─────────────────────────────────────┤
│ 异常标记 🟢🟡🔴                  │── 自动状态灯
└─────────────────────────────────────┘
```

### 核心计算公式
| 指标 | 公式 | 参考范围 | 告警阈值 |
|:----|:----|:---------|:---------|
| 客单价(AOV) | GMV ÷ 订单数 | $10-25 | <$8🟡 / <$5🔴 |
| 净GMV | GMV - 退款金额 - 佣金 - 物流费 | — | — |
| ROAS | GMV ÷ 广告花费 | ≥3.0 及格 | <2.0🟡 / <1.5🔴 |
| GPM | GMV ÷ 总曝光(K) | 美妆工具$80-120 | <$50🟡 / <$30🔴 |
| 出单率 | 有出单SKU ÷ 总上架SKU | ≥30% 及格 | <20%🟡 / <10%🔴 |
| 退款率 | 退款订单 ÷ 总订单 | ≤5% 健康线 | >10%🟡 / >20%🔴 |

### 异常标记逻辑
| 状态 | 判定规则 | 操作 |
|:----:|----------|------|
| 🟢 正常 | 所有指标在安全区 | 无动作 |
| 🟡 提醒 | 1-2个指标进黄区 | 记录+明早复查 |
| 🔴 告警 | ≥3个指标进黄区 或 1个进红区 | 立即通知土豆 |

## 三、新增：「② 选品效能看板」— 从数据驱动选品

### 为什么需要这张表
当前EchoTik选品→上架→出单→复盘的闭环中，**需要一张表来衡量「选品决策质量」**。

### 字段设计（每行=1个SKU）
```
┌──────────────────────────────────────┐
│  🎯 选品效能 · SKU级追踪            │
├──────────────────────────────────────┤
│ SKU ID │ 产品名称 │ 品类 │ 国家     │── 基础信息
├──────────────────────────────────────┤
│ 上架日期 │ 首单日期 │ 出单周期(天)  │── 时效指标
├──────────────────────────────────────┤
│ 累计GMV │ 累计订单 │ 累计退款       │── 累计业绩
├──────────────────────────────────────┤
│ 7日GMV │ 7日订单 │ 7日GPM         │── 近期热度
├──────────────────────────────────────┤
│ 视频数 │ 总播放量 │ 转化率         │── 视频带动效果
├──────────────────────────────────────┤
│ 1688拿货价 │ 定价 │ 毛利率 │       │── 利润分析
├──────────────────────────────────────┤
│ 供应商名 │ 等级 │ 状态             │── 供应商绑定
├──────────────────────────────────────┤
│ 🎯 评分 │ 生命周期状态             │── 决策辅助
└──────────────────────────────────────┘
```

### SKU生命周期状态机
```
上线 → 7天考察期 → 判定：
├── ✅ 热销（日>5单）→ 主推
├── ⚡ 平销（日1-5单）→ 持续观察
├── ⏳ 换品预警（日<1单且7天累计<5单）→ 准备替换
└── ❌ 放弃（14天<5单且无起色）→ 下架
```

### 关键决策输出
| 场景 | 条件 | 自动触发 |
|:----|:-----|:---------|
| 🔥 爆款加单 | 单SKU连续5日>10单 | 通知土豆补货/加投广告 |
| ⚡ 补品建议 | 某品类出单率<20% | 通知番茄补充选品 |
| 🔄 换品建议 | SKU给14天仍未出单 | 告知生菜换文案，3天后仍无→下架 |
| 📦 缺货预警 | 库存<3天销量 | 提前通知供应商补货 |
| 🎯 视频匹配 | 播放量高但转化低 | 建议优化商品详情页 |

## 四、新增：「③ 供应商健康看板」

### 字段设计
```
┌──────────────────────────────────────┐
│  🏭 供应商健康度 · 实时监控         │
├──────────────────────────────────────┤
│ 供应商名 │ 等级(S/A/B) │ 品类       │── 基础
├──────────────────────────────────────┤
│ 合作SKU数 │ 累计订单 │ 累计金额     │── 合作深度
├──────────────────────────────────────┤
│ 近7日发货时效：<24h/24-48h/>48h占比  │── 时效分布
├──────────────────────────────────────┤
│ 发货及时率 │ 质量评分 │ 售后响应h   │── 质量指标
├──────────────────────────────────────┤
│ 最近异常日 │ 异常次数(累计) │ 状态   │── 风险指标
├──────────────────────────────────────┤
│ 综合健康分(自动计算)│ 建议动作       │── 决策输出
└──────────────────────────────────────┘
```

### 自动健康分计算
```
健康分 = 发货及时率×30% + 质量评分(×20/5)×20% + 
         售后响应分×20% + 价格稳定分×15% + 合作时长分×15%
         
其中：
- 售后响应分：<1h=100, 1-3h=80, 3-6h=60, >6h=40
- 价格稳定分：60天不涨=100, 30天=80, 15天=50
- 合作时长分：>6月=100, 3-6月=80, 1-3月=60, <1月=40

等级划分：
≥85：S级 | 70-84：A级 | 55-69：B级 | <55：淘汰
```

## 八、data_monitor.py 升级建议

### 当前问题
1. **飞书webhook未配置** → 无法自动推送
2. **只有异常检测** → 缺乏常规日报/周报推送
3. **模拟数据** → 尚未对接TikTok API
4. **阈值固定** → 建议改为「阶段自适应阈值」

### 推荐升级方向
| 模块 | 当前 | 升级后 |
|:----|:-----|:-------|
| 数据源 | 模拟数据 | TikTok API拉取 → 飞书多维表格写入 |
| 推送 | 单一webhook | 群机器人+卡片+维度表联动 |
| 检测范围 | 4个阈值 | 15+指标分三级阈值 |
| 智能程度 | 固定阈值 | 阶段自适应（起步期/爬坡期/稳定期阈值不同） |
| 报表周期 | 无 | 每日日报/每周周报/月报 |

### 升级代码框架建议

```python
# data_monitor_v2.py 核心模块建议
class DashboardV2:
    def __init__(self):
        # 连接飞书多维表格
        self.bitable = FeishuBitable(BITABLE_APP_TOKEN)
        # 连接TikTok API
        self.tiktok = TikTokAPI(api_key, api_secret)
        
    def daily_sync(self):
        """每日同步：拉数据→洗数据→写入→检查异常→推送"""
        # 1. 拉取昨日各国数据
        raw_data = self.tiktok.get_yesterday_stats(countries=["TH","MY","VN","PH","SG"])
        # 2. 计算衍生指标（客单价/净GMV/出单率等）
        cooked = self.calculate_metrics(raw_data)
        # 3. 写入飞书多维表格（驾驶舱表）
        self.bitable.append("驾驶舱", cooked)
        # 4. 异常检测
        alerts = self.check_all_alerts(cooked)
        # 5. 如果有异常，推送飞书卡片
        if alerts:
            self.push_alerts(alerts)
        # 6. 记录GEP
        self.gep_record("daily_sync", "success")
```
