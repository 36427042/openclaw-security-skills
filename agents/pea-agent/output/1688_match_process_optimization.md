## 四、供应商自动评分方案

### 评分公式（5维度加权）

```
综合分 = 跨境专供分(15%) + 发货分(20%) + 质量分(25%) + 售后分(25%) + 稳定分(15%)

各维度得分规则：
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

① 跨境专供分（最高15分）
   有跨境专供标识              → 15分
   虽无标识但有跨境经验        → 10分
   仅国内批发                  → 5分
   无信息                      → 0分

② 发货分（最高20分）
   <24小时发货 + 发货及时率≥98%   → 20分
   <24小时发货 + ≥95%             → 17分
   <48小时发货 + ≥95%             → 14分
   <48小时发货 + ≥90%             → 10分
   <72小时                        → 5分
   >72小时                        → 0分（淘汰线）

③ 质量分（最高25分）
   综合评分4.8+                  → 25分
   综合评分4.5-4.7               → 20分
   综合评分4.0-4.4               → 15分
   综合评分<4.0                  → 0分（淘汰线）

④ 售后分（最高25分）
   售后响应<1h + 商家担运费       → 25分
   售后响应1-3h + 商家担运费      → 20分
   售后响应3-6h + 部分担运费      → 15分
   售后推诿/不担运费              → 5分
        
⑤ 稳定分（最高15分）
   60天不涨价 + 月销1000+         → 15分
   30天不涨价 + 月销500+          → 12分
   15天不涨价                     → 8分
   价格波动频繁                   → 3分
```

### 等级与动作
| 综合分 | 等级 | 动作 |
|:-----:|:----:|:-----|
| ≥85 | 🏆 S级 · 主力 | 优先派单，每月超1000单可谈优惠 |
| 70-84 | ✅ A级 · 备选A | 主力断货/降级时启用 |
| 55-69 | ⚡ B级 · 备选B | A级断货时启用 |
| 40-54 | ⏳ 考察期 | 再给2周观察，无改善淘汰 |
| <40 | ❌ 淘汰 | 立即停止合作+飞书通知 |

## 五、供应商档案自动维护方案

### 使用飞书多维表格维护

```
📋 表：供应商档案（主表）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
字段                    类型          说明
────────────────────────────────────────────────
供应商ID               自动编号      唯一标识
1688店铺名             文本          可点链接跳转
店铺URL                链接          
主营品类               多选          美妆工具/家居用品/个人洗护/其他
跨境专供               单选          是/否
发货时效               单选          <24h/<48h/<72h/+72h
发货及时率             数字(%)       每周自动更新
综合评分               数字(1-5)     1688店铺星级
描述相符               数字(1-5)     1688评分
服务态度               数字(1-5)     1688评分
物流服务               数字(1-5)     1688评分
售后响应时间           数字(h)       统计最近5次响应
价格稳定性             单选          60天不涨/30天不涨/15天不涨/频繁波动
合作月数               数字          自动计算
月均订单数             数字          累计/合作月数
异常次数               数字          从关联表汇总
自动健康分             公式          综合评分公式
等级(S/A/B/考察/淘汰)  公式          根据健康分自动计算
最后更新日期           日期          一周内更新标记同步
状态                   单选          合作中/考察中/已淘汰
备注                   长文本        特殊情况说明
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 自动更新机制
```
每周一 09:00 → 飞书定时任务触发：

1. 📥 拉取所有合作中供应商的订单数据
   · 总订单数、异常单数、发货时效分布
   
2. 📊 更新各维度数据
   · 发货及时率 = 按时发货订单 ÷ 总订单
   · 售后响应 = 平均5次响应时间
   · 最后异常日 = 最近一次异常日期

3. 🏭 重新计算健康分+等级
   · 分数变化 >10分 → 飞书通知
   · 等级变化 → 飞书卡片推送 + 建议动作

4. ⚠️ 检查淘汰线
   · 触发淘汰条件的 → 自动标记+通知苦瓜审
```

## 七、全流程优化总结

### 新旧流程对比

| 环节 | 🟢 旧流程 | 🟢 新流程 |
|:----|:---------|:---------|
| 启动时机 | 等选品确认后才搜索 | 提前建立供应商池，选品确认后直接匹配 |
| 搜索耗时 | 每个品类30分钟 | 一次性70分钟建池，后续匹配仅需10分钟 |
| 评分方式 | 凭印象/手动打分 | 5维度自动公式计算，可量化可追溯 |
| 档案维护 | 手动记录，易遗忘 | 飞书多维表格+自动更新+淘汰提醒 |
| 候选输出 | 纯文本/Word | 结构化模板，一眼可读 |
| 批量支持 | 一个一个手动处理 | 自动批量匹配50个SKU |

### 剩余阻塞点
| 阻塞项 | 当前状态 | 依赖 |
|:-------|:--------:|:-----|
