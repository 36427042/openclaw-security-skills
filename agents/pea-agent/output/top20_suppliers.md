1. **交叉比价**：每个SKU至少比对3家1688供应商
2. **样品验证**：首批采购前，花¥500-1000买样验证品质
3. **议价空间**：报价通常可降10-20%（前提是起批量翻倍）
4. **组合采购**：同类产品安排同厂采购（如假睫毛3款+镊子+胶水组合）
