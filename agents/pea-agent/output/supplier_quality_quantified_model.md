# 🫘 供应商质量评估量化模型 — 从S/A/B/C到精准评分

> **创建时间**：2026-05-11 05:55 GMT+8
> **作者**：🫘豌豆
> **目的**：在第一轮S/A/B/C分级基础上，深度细化1688店铺维度的量化评分公式
> **核心**：供应商评分不是一次性的——是每新增一个数据维度就更新一次的「活分」

---

## 一、评分模型升级总览

### 从第一轮5维度到本轮8维度

```
第一轮（5维度）:         本轮（8维度 + 纠纷权重）:
  跨境专供分(15%)         跨境专供/经验(10%)
  发货分(20%)             发货分(15%) 
  质量分(25%)    ──→     质量分(20%)
  售后分(25%)             售后分(15%)  
  稳定分(15%)             稳定分(10%)
                          店铺年限(10%)      ← 新增
                          回头率(10%)        ← 新增
                          纠纷率权重(自动降档) ← 新增独立惩罚机制
```

### 为什么需要精细化？
- 5维度粗分把「新店但产品好」和「老店但服务烂」混在一起
- 新店≠烂店——老店也可能躺平，新店也可能冲销量
- 纠纷率是致命指标——1个纠纷单的杀伤力 > 10个好评分

## 二、新版评分公式（8维度+惩罚机制）

### 主公式
```
供应商综合评分 = 
    ∑ 各维度得分 × 各维度权重
    × 纠纷惩罚系数
    × 响应速度加成分

纠纷惩罚系数 = 纠纷率≤2%→1.0(无惩罚)
            纠纷率2-5%→0.85
            纠纷率5-10%→0.50  ← 直接腰斩
            纠纷率>10%→0.20(自动降级2档)

响应速度加成分 = <1h→1.05 | 1-3h→1.0 | 3-6h→0.95 | >6h→0.90
```

### 8维度详细评分标准

#### 维度① 跨境专供/经验 — 权重10%

| 条件 | 得分 | 判断依据 |
|:-----|:----:|:---------|
| 有「跨境专供」标识 + 已出过跨境单 | 100分 | 1688店铺标注 |
| 有「跨境专供」标识 | 85分 | 标识可见 |
| 无标识但有跨境经验（描述中含海外/出口/跨境） | 70分 | 店铺描述分析 |
| 仅国内批发 | 40分 | — |
| 无店铺信息 | 0分 | — |

#### 维度② 发货分 — 权重15%

| 条件 | 得分 | 说明 |
|:-----|:----:|:-----|
| 24小时发货 + 发货及时率≥98% | 100分 | 行业TOP级 |
| 24小时发货 + 发货及时率≥95% | 85分 | 优秀 |
| 48小时发货 + 发货及时率≥95% | 70分 | 合格 |
| 48小时发货 + 发货及时率≥90% | 50分 | 一般 |
| 72小时发货 | 30分 | 偏慢 |
| >72小时或未标注 | 10分 | 淘汰候选 |

**发货准确率精细化公式**（新增）：
```
发货准确率 = 正确发货订单数 ÷ 总订单数 × 100%

精细化拆解：
- 数量准确率 = 数量无误订单 ÷ 总订单 × 50%
- 规格准确率 = 规格无误订单 ÷ 总订单 × 30%
- 包装完好率 = 包装无破损订单 ÷ 总订单 × 20%

发货分 = 发货时效分(60%) + 发货准确率分(40%)
```

#### 维度③ 质量分 — 权重20%

| 条件 | 得分 | 说明 |
|:-----|:----:|:-----|
| 描述相符≥4.8 + 综合评分≥4.8 | 100分 | 顶级 |
| 描述相符4.5-4.7 + 综合评分4.5-4.7 | 85分 | 优秀 |
| 描述相符4.0-4.4 + 综合评分4.0-4.4 | 65分 | 合格 |
| 描述相符<4.0 或 综合评分<4.0 | 30分 | 降级候选 |
| 无评分数据或无数据 | 10分 | 谨慎使用 |

**质量分公式（加权）**：
```
质量分 = 描述相符评分(35%) + 综合评分(30%) + 好评率(25%) + 首图合格(10%)

*首图合格：店铺主图是否清晰、有尺寸说明
```

#### 维度④ 售后分 — 权重15%

| 条件 | 得分 | 说明 |
|:-----|:----:|:-----|
| 售后响应<1h + 商家无条件担运费 | 100分 | 优秀售后服务 |
| 售后响应1-3h + 商家担运费(协商后) | 80分 | 良好 |
| 售后响应3-6h + 部分担运费 | 55分 | 及格 |
| 售后推诿/不担运费/不理 | 20分 | 差评 |
| 有实际纠纷记录 | 10分 | 回避 |

**售后响应速度精细化**：
```
售后响应分 = 最近5次响应时间的中位数，换算：
<30min → 加5分（超快速加分）
30min-1h → 0分（标准）
1-3h → -5分
3-6h → -15分
>6h → -25分
```

#### 维度⑤ 稳定分 — 权重10%

| 条件 | 得分 | 说明 |
|:-----|:----:|:-----|
| 60天内价格稳定 + 月销≥1000 | 100分 | 超稳定 |
| 30天内价格稳定 + 月销≥500 | 85分 | 稳定 |
| 15天内价格稳定 + 月销≥200 | 65分 | 基本稳定 |
| 价格波动频繁 | 30分 | 不稳定 |
| 月销持续下滑 | 20分 | 危险信号 |

**价格稳定性检测公式**：
```
价格稳定性 = 1 - (最高价 - 最低价) / 常售价

示例：常售价¥20，观察期最高¥22，最低¥18
价格稳定性 = 1 - (22-18)/20 = 1 - 0.2 = 0.8(80分)
```

#### 维度⑥ 店铺年限 — 权重10% ← 新增

| 条件 | 得分 | 说明 |
|:-----|:----:|:-----|
| 3年以上 + 年销售额≥500万 | 100分 | 老牌靠谱 |
| 2-3年 + 年销售额≥200万 | 85分 | 稳定运营中 |
| 1-2年 | 65分 | 成长中 |
| 6-12个月 | 45分 | 新店需观察 |
| <6个月 | 25分 | 高风险新店(新店跑路/虚假发货) |

**为什么新店风险高？**
```
┌────────────────────────────┐
│ 新店(<6月)经典风险场景：     │
│                            │
│ 1. 虚拟库存（接单才采购）→ 延迟发货 │
│ 2. 质检不成熟 → 客户退款率飙升  │
│ 3. 运营不稳定 → 随时可能关店  │
│ 4. 被钓鱼订单坑 → 货发错了   │
│ 5. 没跨境经验 → 不懂出口要求  │
└────────────────────────────┘
```

#### 维度⑦ 回头率 — 权重10% ← 新增

| 条件 | 得分 | 说明 |
|:-----|:----:|:-----|
| 回头率≥50% | 100分 | 超强客户粘性 |
| 回头率30-50% | 85分+加分 | **回头率>30%加5分** |
| 回头率20-30% | 70分 | 正常范围 |
| 回头率10-20% | 55分 | 偏低 |
| 回头率<10% | 30分 | 几乎无复购，警惕 |

**「回头率>30%加分」规则**：
```
回头率>30%时：
总评分 = 原评分 + 5分（在最终分数上加）

回头率>50%时：
总评分 = 原评分 + 10分（在最终分数上加）

*加分的理由是：高回头率证明供应商的产品质量稳定、
 价格合理、服务到位，复购客户已经用脚投票了
```

#### 维度⑧ 纠纷率 — 独立惩罚机制 ← 新增

| 条件 | 惩罚系数 | 等级降档 |
|:------|:-------:|:--------:|
| 纠纷率≤2% | ×1.0(无影响) | 不降档 |
| 纠纷率2%-5% | ×0.85 | 不降档但标记🟡 |
| 纠纷率5%-10% | ×0.50 | ⬇️降1级 |

| 纠纷率>10% | ×0.20 | ⬇️⬇️降2级 |
| 纠纷率>15% | ×0.10(must=0) | ❌直接淘汰 |

**纠纷率加权算法**：
```
纠纷率 = (近30天纠纷单数 + 近30天退款单数×0.5) ÷ 近30天总订单数

权重说明：纠纷单(真冲突)权重1，退款单(仅退款)权重0.5
所以同样的纠纷率 10% = (10单纠纷+0退款) vs 10% = (0纠纷+20退款)
后者更可能是客户问题，所以用加权区分
```

## 三、完整评分计算示例

### 示例1：优秀老供应商
```
背景：3年老店(美妆工具)，有跨境专供，发货快，回头率45%

维度得分：
① 跨境专供: 100分 × 10% = 10.0
② 发货: 发货时效100分×60% + 发货准确98分×40% = 99分 × 15% = 14.85
③ 质量: 描述相符95分×35%+综合100分×30%+好评92分×25%+首图90分×10%=95分 × 20% = 19.0
④ 售后: 响应快100分 × 15% = 15.0
⑤ 稳定: 100分 × 10% = 10.0
⑥ 年限: 3年老店100分 × 10% = 10.0
⑦ 回头率: 45%→85分 + 加5分(>30%) = 90分 × 10% = 9.0

小计 = 10.0+14.85+19.0+15.0+10.0+10.0+9.0 = 87.85

调整：
纠纷率1.2%≤2% → 无惩罚 ×1.0
响应<30min → 加权 +5分(超快速响应加分)

最终 = 87.85 × 1.0 + 5 = 92.85分 → 🏆S级
```

### 示例2：新店但产品好
```
背景：成立5个月的美妆工具店，产品评分高，但店铺新

维度得分：
① 跨境专供: 有标识85分 × 10% = 8.5
② 发货: 24小时发货98分×60%+准确率90分(数据不足)×40% = 95分 × 15% = 14.25
③ 质量: 描述相符4.8→100分 × 60% = 60  ← 单维度细化取top
④ 售后: 1-3h响应80分 × 15% = 12.0
⑤ 稳定: 15天稳定65分 × 10% = 6.5
⑥ 年限: <6个月 → 25分 × 10% = 2.5
⑦ 回头率: 5% → 30分 × 10% = 3.0

小计 = 8.5+14.25+12.0+6.5+2.5+3.0 = 46.75

调整：
纠纷率0% → ×1.0
响应快 → +0分(标准)

最终 = 46.75分 → ⏳考察期(B降为考察)

建议：不作为主力，小批量测试1-2个月，期间设观察期
      如果月订单5单且0纠纷 → 60天后重新评估
```

### 示例3：老店但纠纷率高
```
背景：5年老店，回头率也高，但纠纷率8%

维度得分：
① 跨境专供: 100分 × 10% = 10.0
② 发货: 24h发货95分 × 15% = 14.25
③ 质量: 4.5-4.7→85分×20%=17.0
④ 售后: 1-3h响应80分×15%=12.0
⑤ 稳定: 60天稳定100分×10%=10.0
⑥ 年限: 5年100分×10%=10.0
⑦ 回头率: 40%→85分+5分(>30%)=90分×10%=9.0

小计 = 10.0+14.25+17.0+12.0+10.0+10.0+9.0 = 82.25

调整：
纠纷率8%(>5%) → ×0.50(腰斩)
响应1-3h→0分

最终 = 82.25 × 0.50 + 0 = 41.13分 → ⚠️降1级(S→A)
```

## 四、产品-供应商匹配度评分公式

### 为什么需要匹配度评分？
同一个供应商对不同产品来说匹配度不同——S级供应商不一定适合所有产品。

### 匹配度评分公式
```
匹配度 = 供应商综合评分 × 0.30
       + 拿货价契合度 × 0.25          ← 这家供应商的价格区间是否覆盖目标价
       + 品类契合度 × 0.20            ← 供应商是否主要做这个品类
       + 过往合作分 × 0.15            ← 如果有过合作记录
       + 产能匹配 × 0.10              ← 能否满足首批+补货量的产能
```

#### 拿货价契合度
```
拿货价契合度 = 1 - |目标价 - 供应商均价的差距| / 目标价格带宽度

示例：目标拿货价¥5，供应商主要产品¥3-8(宽度¥5)
      供应商平均拿货价约¥5.5
      差距=¥0.5，宽度=¥5
      契合度 = 1 - 0.5/5 = 1 - 0.1 = 0.9(90分)
```

#### 品类契合度
```
品类契合度 = 该品类 SKU数 ÷ 供应商总SKU数 × 100

示例：该供应商100个SKU中40个是美妆工具
      品类契合度 = 40/100 = 40分
      
      >50% → 高度契合
      30-50% → 部分契合
      <30% → 低契合（这家店只是顺带做这个品类）
```

#### 过往合作分
```
无合作记录 → 50分（中性分，既不加分也不减分）
有1-5单合作 → 60分 + 其中满意度(0-40分)
有>5单合作 → 根据实际数据：按准时交货率60%+质量偏好30%+退款率10%算
```

#### 产能匹配
```
首批300个 + 补货480个/周 = 每周约需780个
                    ↓
供应商标注月销: 5,000个/月 = 1,250个/周
对比：需求780 < 产能1,250 → ✅ 有充足产能

产能匹配分 = min(总产能÷月需求, 1.0) × 100
但如果产能不足70% → 按比例降分（避免逼迫超产能导致品控下降）
```

### 匹配度等级

| 匹配度 | 等级 | 建议动作 |
|:-----:|:----:|:---------|
| ≥90分 | 🏆S匹配 | 直接主力供应商 |
| 75-89分 | ✅A匹配 | 可直接合作 |
| 60-74分 | ⚡B匹配 | 可备选或联系确认后启用 |
| 40-59分 | ⏳C匹配 | 需要更详细调研或找替代 |
| <40分 | ❌D匹配 | 不推荐（匹配度太低） |

## 六、自动化维护流程

### 每周一自动更新
```
09:00 触发 → 飞书定时任务

步骤1：拉取本周数据
       · 各供应商订单数据（总订单/异常单/退款单数）
       · 售后响应时间统计
       · 纠纷单数

步骤2：更新字段
       · 发货准确率 = 正确数/总订单
       · 纠纷率 = 加权纠纷数/总订单
       · 回头率 = (有复购客户数/总客户数)
       · 各维度重算 → 最终评分重算 → 等级重算

步骤3：异常通知
       · 降级：S→A 或 A→B → 通知土豆
       · 纠纷率>5% → 通知🥒苦瓜(风控)
       · 纠纷率>10% → 自动降1级 + 通知团队
       · 某供应商连续2周>85分但被忽视 → 提示启用

步骤4：淘汰清理
       · 连续3周D级 → 自动标记「淘汰建议」
       · 连续无订单45天 → 标记「僵尸」→ 冷处理
```

## 七、与第一轮方案的对比

| 对比项 | 第一轮(S/A/B/C) | 本轮(8维度量化) | 收益 |
|:-------|:---------------:|:---------------:|:----:|
| 评分维度数 | 5个 | 8个 | 评估更全面 |
| 纠纷处理 | 无独立惩罚机制 | 独立惩罚系数，最高降2级 | 🔴致命指标不遗漏 |
| 响应速度 | 含在售后分中 | 独立加权，<1h加分 | 鼓励快速响应 |
| 店铺年限 | 无考虑 | 独立10%权重 | 🆕新店风险识别 |
