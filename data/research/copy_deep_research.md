## 1. 5国违禁词最新政策

### 🇹🇭 泰国：Thai FDA 最新指南（2025年8月更新，11月发布）

**泰国 FDA 2025版违禁词指南核心更新 (Guidelines for the Consideration of Words Prohibited, Rev. Aug 22, 2025)：**

| 违禁类别 | 具体禁止词汇/表述 | 说明 |
|---------|-----------------|------|
| ✅ **医疗/药物暗示** | "รักษา" (treat), "หาย" (cure), "ยารักษาโรค" (medicine), 任何暗示产品是药物的词汇 | 绝对禁止 |
| ✅ **夸大功效** | "ขาวใน7วัน" (白7天), "เห็นผลทันที" (即刻见效), "เปลี่ยนหน้าสวยในชั่วข้ามคืน" (一夜变脸) | 时间承诺类全部禁止 |
| ✅ **虚假等级** | "อันดับ1" (#1), "ดีที่สุด" (best), "ที่สุด" (the most), "อันดับหนึ่ง" (top/ranking claims) | 除非有第三方认证数据 |
| ✅ **医学人士背书** | 医生(แพทย์ / หมอ)、药师(เภสัชกร)形象、姓名或推荐 | 严格禁止 |
| ✅ **违禁成分暗示安全** | 暗示产品含"汞/氢醌/维A酸/类固醇"等违禁成分但声称安全 | 新规重点 |
| ✅ **"Instant"类时间词** | "ทันที" (immediately), "เร็ว" (fast), "ปุ๊บปั๊บ" (instantly) | 严格受限 |

**⚠️ 特别警示（美妆工具类）：**
- "กระชับรูขุมขน" (pore tightening) — 如果是工具类，慎用，易被判定为医疗功效
- "ลบรอยสิว" (remove acne scars) — 工具不能"消除"，只能说"ช่วยลดเลือน" (help reduce)
- "ปรับสีผิวให้ขาว" (whiten skin tone) — 极度敏感词
- FDA 针对 "instant whitening" 类宣称产品进行重点抽查

**🔍 核心策略：避免任何医疗/药物暗示，使用"ช่วย" (help) + "ลดเลือน" (reduce/appear diminish) 组合**

### 🇮🇩 印尼：BPOM 化妆品广告管理

**BPOM (Badan POM) 2025年监管力度升级:**

| 违禁类别 | 具体禁止词汇/表述 | 说明 |
|---------|-----------------|------|
| ✅ **医疗功效** | "menyembuhkan" (cure), "mengobati" (treat medically), "terapi" (therapy) | 严格禁止 |
| ✅ **绝对化宣称** | "100%", "paling ampuh" (most effective), "terbaik" (best), "satu-satunya" (only) | 无数据支撑不得使用 |
| ✅ **美白速效** | "putih instan" (instant white), "putih permanen" (permanent white), "putih dalam 3 hari" | BPOM重点监管对象 |
| ✅ **成分违规暗示** | "bebas merkuri" (but shouldn't contain mercury anyway — implies the category does) | 新规关注点 |
| ✅ **医生/专家背书** | "rekomendasi dokter" (doctor's recommendation), "dokter kulit" (dermatologist), "BPOM-approved" — 但BPOM本身要求不能滥用 | |

**⚠️ 🇮🇩 特别关注：**
- BPOM 2025年12月发布报告：发现26款含危险成分化妆品（维A酸、莫米松、氢醌等）
- "Putih mulus" (white and smooth) — 关联重金属风险词汇，易触发电商平台审核
- "Cantik" (beautiful) 本身安全，但 "Cantik itu harus putih" (beautiful must be white) — BPOM官方也在反对这个观念
- TikTok Shop Indonesia 2025加强：对所有声称"whitening/menghilangkan flek hitam"的产品要求提供BPOM注册号

**🔍 核心策略：强调"merawat" (care for) > "mengubah" (change/transform)；使用"tampak lebih cerah" (look brighter) 而非 "putih" (white)**

### 🇻🇳 越南：Bộ Y Tế（卫生部）新规草案 + TikTok Shop政策

**2025年越南卫生部化妆品广告新政草案核心内容：**

| 违禁类别 | 具体禁止词汇/表述 | 说明 |
|---------|-----------------|------|
| ✅ **禁止引起误解为药品** | "trị nám" (treat melasma), "trị mụn" (treat acne) — 除非有药品注册证 | ⚠️ 这是最大雷区 |
| ✅ **绝对化效果** | "khỏi hẳn" (completely cured), "hết sạch" (completely gone), "tận gốc" (from the root) | 最容易被举报 |
| ✅ **医疗人士背书** | 禁止使用医生/药剂师/护士/医疗研究人员的姓名、信件、文章、照片来推广化妆品 | 新规明确要求 |
| ✅ **时间承诺** | "sau 3 ngày" (after 3 days), "trong 1 tuần" (in 1 week), "hiệu quả tức thì" (immediate results) | 严格禁止 |
| ✅ **违禁成分** | 禁止声称产品含有"thủy ngân/hydroquinone/acid retinoic"但标注"tuyệt đối an toàn"（绝对安全） | FDA重点扫查点 |

**⚠️ 🇻🇳 特别关注：**
- 越南卫生部2025年加强TikTok/Facebook平台化妆品销售检查
- "Trắng da sau..." (white skin after...) — 时间类白承诺已被大量处罚
- "Xóa nhăn" (erase wrinkles)、"căng bóng" (firm and glossy) — 工具类慎用这些效果词
- 新规要求广告内容必须与申报文件一致，不得超出声明功效范围

**🔍 核心策略：用"hỗ trợ" (support/help) + "cải thiện" (improve) 组合；绝对避免"trị" (treat)、"khỏi" (cured)；强调 "chăm sóc da" (skin care)**

### 🇲🇾 马来西亚：NPRA + 清真合规特殊要求

| 违禁类别 | 具体禁止词汇/表述 | 说明 |
|---------|-----------------|------|
| ✅ **医疗宣称** | "merawat" (treat), "menyembuhkan" (cure), "mengubati" (medically treat) | 严格禁止 |
| ✅ **绝对化** | "terbaik" (best), "paling selamat" (safest), "#1 di Malaysia" | 除非有可验证证据 |
| ✅ **美白/漂白** | "memutihkan" (whiten), "pemutihan" (bleaching), "cerah dalam seminggu" | NPRA监管重点 |
| ✅ **清真敏感** | 如果产品没有JAKIM清真认证，**不得在标题/描述中使用"halal"暗示** | 🇲🇾 独有！ |
| ✅ **宗教敏感** | 避免使用宗教意象、回教圣词关联美容效果（barakah等） | 非常敏感的合规点 |

**⚠️ 🇲🇾 特别关注：**
- Malaysia NPRA 与 Ministry of Health 联合行动频次增加
- TikTok Shop Malaysia 2025年对化妆品内容审核升级
- "Glowing" 安全，但 "glowing mulus sempurna" (perfect glow) 可能会被判定为夸大
- 马来西亚消费者对"bahan semulajadi" (natural ingredients) 特别敏感——如果声称天然须有支撑
- 清真化趋势：穆斯林消费者占多数，提"halal"但未认证会导致法律问题

**🔍 核心策略：使用"lembut" (gentle), "selesa" (comfortable), "berseri" (radiant) 这类温和词；清真用"mesra muslim" (muslim-friendly) 替代未认证产品**

### 🇵🇭 菲律宾：FDA 化妆品合规监管

| 违禁类别 | 具体禁止词汇/表述 | 说明 |
|---------|-----------------|------|
| ✅ **未授权产品声明** | 任何未取得CPN(Certificate of Product Notification)的产品，不得宣称功效 | 2025年大规模通报 |
| ✅ **美白/漂白** | "whitening" — 高度审查，菲律宾FDA定期通报未授权美白产品 | 重点打击 |
| ✅ **医疗宣称** | "cure", "treat", "heal", "therapy" | 化妆品不可用 |
| ✅ **夸张保证** | "instant", "guaranteed", "100%", "miraculous" | 严格限制 |
| ✅ **医生背书** | "dermatologist-recommended", "derma-tested" — 必须有能力提供临床证据 | |

**⚠️ 🇵🇭 特别关注：**
- Philippines FDA 2025年发布 Circular No. 2025-002：更新东盟化妆品指令（ACD）采纳
- 大量美白产品被通报：Skinlight Whitening Cream, BeautyTrends Peel Off Mask Whitening等
- "Puti" (white) 在Tagalog中单独使用一般来说安全（陈述性质），但"pumuti" (become white) 属于功效宣称
- 菲律宾消费者对"korean"、"glass skin"、"glow"类词汇接受度极高，这些相对安全
- "FDA approved" 在菲律宾不能随便说 — 化妆品用"notified" 而非 "approved"

**🔍 核心策略：用"glow", "radiance", "brightening" 替代 "whitening"；强调 "skin care routine" 而非 "treatment"**

## 3. 高转化话术模式

### 核心转化话术结构 (TikTok Southeast Asia适用)
