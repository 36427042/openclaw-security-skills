# 选品方向（天赐版）

## 3大预设品类（明确锁定）
1. **美妆工具** — 粉扑/化妆刷/睫毛夹/眉笔/唇泥/美妆蛋/眼线笔等
2. **家居用品（<500g）** — 收纳盒/收纳袋/衣架/抹布/清洁刷/防滑垫/挂钩/垃圾桶/除垢刷/分隔板
3. **日用品** — 洗脸巾/棉签/香皂片/干发帽/化妆镜/指甲刀/梳子/洗衣皂/湿巾/牙刷

**重量限制**：家居用品单件<500g，轻小件适合一件代发

## 核心逻辑
1. 通过 EchoTik API 拉取 **5国（泰/马/印/菲/越）** 以上3个品类的实时数据
2. 筛选标准：按 `02_选品核心标准.md` 的8条条件+排除项
3. 每个品类找到10个方向，每个方向选2款爆品
4. 排序方式：GPM → 销量涨幅 → 竞争度

## 数据来源
- EchoTik: 商品搜索 / 品类榜单 / 热门趋势 / 达人带货
- 配合 Sorftime 后验验证

## 一句话
**3个品类锁定，数据决定具体选哪款**
